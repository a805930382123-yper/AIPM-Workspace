# RAWOCR04 历史配图派生迁移

用户已授权第四轮，基线 `c5432c9`。本卡在施工前冻结。依据 RAWOCR01–03 既有契约及当前源码；此前未找到的独立原规格正文仍不得声称已核对。采用 agent-router：明确度 1（冻结迁移入口）、耦合 2（存储、迁移、阅读）、风险 2（历史保真）、历史失败 0，合计 5，B 模式。Astra medium 规划及独立验收，Sol High 施工；实际实例由主 Agent 创建记录确认。

## 最小交付

提供本地显式 CLI 迁移入口与简短运行说明，默认只预览，显式 apply 才写入；支持指定 Raw ID，允许显式全部选择。无需新增管理页面、后台任务、调度器或迁移数据库。本轮仅在系统临时目录的隔离数据执行，交付可操作工具，不运行正式库迁移；真实付费模型预算 0。

迁移只新增缺失的单图派生产物，不删除或重写 Raw 正文中的历史 OCR。普通阅读投影隐藏已识别的历史 OCR 区间并显示派生结果；原始正文、编辑、历史与原文引用保留既有字节与坐标语义。不得用修改 body 后重算哈希的方式冒充保真。

## 接口与所有权

现有 `RawStore.mediaSource` 以 `newsMaterial.revision ?? 0` 读取采集快照，`inspectRawMedia` 返回当前 markers 和应隐藏的 removed 区间；迁移与阅读应复用该判定，避免第三套位置推断。`getAnchoredMediaArtifacts` 与实际 AI 读取链保持一致。最小阅读投影可增加区间数据，原始 body 与原文坐标必须保留。

施工者负责迁移服务/CLI、必要 Raw 读接口和 RawWebContent/RawPage 接线、定向测试及 `docs/reports/RAWOCR04-builder.md`；不扩大成全页重构。规划者只维护本卡；独立验收者写验收脚本与报告；主 Agent 管理状态、验收台账、提交与同步。共享工作区，不覆盖他人修改。

按 `docs/testing.md` 隔离数据、空模型配置及随机端口，按 `docs/evidence-policy.md` 保存证据。交接实际命令/结果、文件清单、基线加 SHA 后施工停写。独立验收分别裁决本轮缺陷与整批，缺少实测不能 PASS。全部必选项完成后主 Agent 提交同步并停止；正式历史库迁移留给后续明确执行指令。
