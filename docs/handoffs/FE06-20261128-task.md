## 等价行为冻结

逐函数/组件对照基线，核 state/ref/effect 初始化顺序、依赖和 cleanup、动作完整函数体、JSX/DOM/class/文案。可用 AST printer 辅助比对，解释每处非机械差异，不能只查导出和字符串。

- 保持 list/create/detail 生命周期、初始材料聚焦、详情迟到响应隔离与 keyed remount；不把 initialId 改造成新的受控导航协议。
- 两类 create payload、失败保留输入、成功清字段/切详情/onChanged 次序不变；搜索/类型/状态组合、空态与重置不变。
- save 的清 notice→busy→action→setSaved→onSaved→notice→onChanged→解锁，以及 remove 的 onChanged→onBack 次序不变；保留所有版本字段、HTTP URL/method/payload、异常分支与错误提示。
- 409 不伪装成功；readLatest 逐字段比较旧 saved 与当前输入，只替换未修改的 context/analysis/report 字段，保留脏字段；同时清建议预览与 stale 状态。保留各区 notice、共享 busy、返回防丢、关闭原因聚焦和删除锁。
- 建议仅预览后人工应用，preview revision、stale 与三项跟进字段的现有合并规则不变；历史、复测结果、报告草稿、发送快照与上海时间格式不变。
- Raw 关联/移除、打开来源回调、本地截图上传/备注/损坏图回退，以及关闭/重开路径保持；Raw 正文不被修改。
- WorkAnalysisPanel 的 props、busy/analysisDirty、reloadItem、saveStage 的来源 run ID、回调及 notices 原样传递；不改其内部行为，模型输出仍只为草稿。
- 全仓告警不高于 750；原页面及迁移模块合计告警不高于原 3 条，不借拆分藏告警，不要求顺手清零。

3. running 记录按原 1200ms 轮询；卸载后清定时器，迟到请求不得继续安排轮询。不增加原实现不存在的取消网络承诺。
4. V1 观察/引文与 V2 摘要/主题/待核项分别呈现；“暂存阶段成果”仅填入可编辑草稿，保存调用 saveStage 时 body 和 analysisRunId 对应所选分析，人工编辑保留，onSaved 按原行为复位。不得直接导出 stageDraft 为测试新增公共 API。
