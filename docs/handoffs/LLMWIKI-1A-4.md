# LLM-Wiki 1A-4 检索评测与整批验收

起点 205baf2。施工 gpt-6.2-sol high 自查，随后由 gpt-6.2-astra medium 独立审查。主 Agent 冻结验收口径、记录阶段状态、提交与同步。评测横跨问答、Prompt、引文与正式文件完整性，采用 B 模式。

| 项目 | 验收要求 |
|---|---|
| 题库与语料 | A/B/C/D/E 各 7/5/5/3/5 题。以真实 Wiki 为主，补充的隔离模拟内容明确标注。首次跑分前记录题目、预期证据/章节、K、负样本定义与指纹，固定比较输入与选页。 |
| 对照 | 两套正式检索路径都要运行，逐题报告命中、章节定位、实际耗时，E 报误召回率；D 核对 12,000 字符场景实际提供的证据。A/C/D 提升，E 不劣化；天花板并列单列，不冒充提升。逐题列出 SQLite B 类漏项。 |
| 性能 | 独立临时数据根生成 1,000 篇 Markdown；计时含读取、切块、中文分词、写库。记录 Legacy 和 SQLite 查询平均/P95；SQLite 建库 <5,000 ms、平均和 P95 均 <50 ms。 |
| 集成 | 三篇长页九个证据点均须命中正确标题路径，逐字引用通过。检查删库重建一致性、故障降级，手工在隔离环境切 legacy_scan 并删除派生库，核实正式入口可用。 |
| 交付 | TypeScript、全量测试、生产构建及工程检查。提交脚本、冻结数据定义和对照快照，附驱动、命令、版本/指纹。独立区分本轮缺陷、阶段裁决和整个 Batch 1A 裁决。 |

仅使用隔离数据进行写入和验证。真实资料留在本地；模拟来源与结果覆盖范围在报告中说明。1B 不在本轮范围。
