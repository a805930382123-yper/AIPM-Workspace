# LLM-Wiki 2B-1 · Wiki 链接与反向引用

基线 `e9e4f12`。本轮沿用逐阶段验收。Batch 2B 的范围来自 2A 提示词，依赖顺序为关系索引与详情反向链接、一跳检索扩展、向量重复提示与整批回归。本卡交付第一阶段。

| 验收项 | 可观察结果 |
|---|---|
| 关系来源 | 正式 Wiki 正文中的 `[[标题]]` 解析为有向边。唯一明确的目标可被关联，自引、重复、歧义、代码示例不产生错误反链。 |
| 一致性 | SQLite 仍是派生索引，所有 SQL 留在既有封装。通过正式入口新建、修订、重命名或删除页面后，目标详情反链与删库重建一致。 |
| 兼容性 | 原始 Markdown、正文、块坐标和逐字引用语义保持一致。索引故障时正式页面保存和详情仍可用。 |
| 回归 | 隔离集成测试、全仓门禁、冻结 25 问离线分类与千页实测。注明运行环境、复用或未测证据。 |
| 交接 | 施工自查并停写，独立验收后由主 Agent 记录、提交及同步。 |

调度评分 5/8，B 模式。标题匹配细则需明确（1），写入、检索索引与详情跨模块（2），索引升级与正文坐标影响数据完整性（2），无本阶段历史返修（0）。GPT-6.2-Sol high 施工，GPT-6.2-Astra medium 独立审查。
