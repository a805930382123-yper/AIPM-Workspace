### A2-01：待处理收件箱结构化与资讯 5 阶段可点击漏斗条（`InboxTab.tsx`）
- **子区轻切换（`.automation-subtabs`）**：
  - 当 `showReminders && hasPipeline` 同时为真时，在 `待处理收件箱` Tab 顶部展示轻切换栏（`role="tablist" aria-label="收件箱分类"`）：
    - `资讯候选`（带实时 `待确认 N` 计数）
    - `事项提醒`（带实时 `未读 M` 计数）
  - 仅单源存在时直接渲染对应模块，不显示多余切换条。
  - `inboxSection: 'candidates' | 'reminders'` 由 `AutomationPage` 受控联动：
    - 从 `流程与计划` 资讯节点（②/③）或 `前往收件箱` 或深链 `candidateFilter` 进入 → `inboxSection = 'candidates'` 并聚焦 `#news-candidate-title`；
    - 从 `流程与计划` 提醒节点（③）或 `前往提醒` 或深链 `focusReminders` 进入 → `inboxSection = 'reminders'` 并聚焦 `#automation-reminders`；
    - 默认进入 `待处理收件箱` Tab → 优先 `'candidates'`（无流水线时为 `'reminders'`）。
- **资讯候选 5 阶段可点击漏斗条（`.automation-funnel`）**：
  - 放在 `#news-candidates` 顶部，视觉对齐首页 `home-a-stages`，展示 5 个连续阶段节点及对应计数（来自 `candidates.counts`）：
    `已抓取` › `待确认` › `整理中` › `待审草稿` › `失败`，并在旁边/右侧提供 `收件箱（全部未忽略）` 与 `已忽略` 快捷切换芯片。
  - 点击阶段节点立即切换列表筛选（`aria-pressed="true"` 高亮语义色标：`待确认`/`待审草稿` → `review`、`失败` → `danger`、有计数其余 → `neutral`、计数 0 → `muted`）；再点击已激活阶段恢复 `'all'`；点击 `待审草稿` 按 `Boolean(row.draftPending)` 过滤。
  - 保持 `.automation-filters` 中的 `资讯日期` `<select>` 与 `候选状态` `<select>`（与漏斗条双向同步，支持 `'drafts'` 选项，并保持 `#news-candidates select` 第 2 个元素为候选状态下拉框，100% 兼容 `uifix02-ui` 与 `autoux01-ui`）、`全选可确认项（N 条）/ 取消全选` 与 `批量确认入库（M 条）`。
- **紧凑候选卡片（`.news-candidate`）**：
  - 将 `AI 预筛` 相关性分值（`3/3` 紫、`2/3` 蓝、`1/3` 灰、`未预筛` 警示灰且保留 `screenError` 文本满足 `/未预筛.*本批读取失败/u` 断言）、建议整理模式（`标准整理`/`深度整理`）、阶段状态收敛为紧凑徽章行 `.automation-candidate-pills`，保留 `aria-label={row.item.title}`、折叠摘录 `<details>`、`.candidate-low`（`relevance === 0` 默认折叠）与全部确认/稍后/忽略/恢复/打开 Raw/审核草稿/重试/查看运行按钮。
