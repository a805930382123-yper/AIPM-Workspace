# NEWSRAW02 独立验收

**本轮缺陷修复 PASS。** 从旧收据仍存在、Raw 已删除、自动整理执行已失败的状态开始，指定文章连续三次重新采集成功。每次删除后均能从另一个入口重建，旧失败状态和旧草稿没有带到新 Raw。

**批次整体验收 PASS。** 两个入口都能分别显示已保存 Raw、草稿待确认和正式入库。只有确认成功后才出现「已导入知识库」，两边都打开了本次确认创建的知识主题。

## 真实来源与操作

2026-11-23，在临时数据目录启动生产模式服务及独立 Chrome。从上轮隔离样例复制当日日报、指定候选、旧确认与失败记录、指向已删 Raw 的收据。使用不存在的 LLM 配置并清除继承凭据。抓取使用默认公开来源客户端和实际 OCR。[卡兹克三模型协作原文](https://mp.weixin.qq.com/s/gwj0xLNHPfToQnQJN7IkMA)

| Chrome 操作 | 新 Raw ID | 采集时间（UTC） |
| --- | --- | --- |
| 每日资讯 → AI 前沿 → 原 Raw 已删除 → 重新导入 Raw | 279542a1-df14-4aa1-8f33-bfcf26ce9b06 | 04:43:02.672 |
| 删除后从收件箱重新导入，关闭自动整理，确认并入库 | 223f7fa0-7ca0-4f08-bc08-06adf599f8f3 | 04:44:56.142 |
| 再次删除，从每日资讯重新导入 | f6636754-1773-4fc8-80ef-ce4ae1d300f1 | 04:45:58.011 |

两次删除均调用隔离产品的 `DELETE /api/raw/:id`，随后读取旧 ID 均返回 404。每次保存后 Raw 列表仅一条。三份正文均为 15,203 个字符、9 张图片，正文 SHA-256 均为 `f16a629b227ae4185b05d19095f284126b45ca9fe48d4fb200bcb53bebe2aa91`。第三次逐个核对全部图片文件与元数据的 SHA-256，9/9 一致。

为第三个 Raw 创建隔离草稿。两边均出现待确认状态，分别点击审核入口，都打开此草稿的整理成果。通过产品 HTTP 接口核对草稿页、明确确认选中知识页，服务返回 `completed` 和知识条目 ID `aaf68fdb-68ab-4e78-86b1-9afc1176fb81`。再次分别进入每日资讯和收件箱，两处均显示「已导入知识库 · 查看条目」，点击后均看到知识库的「卡兹克三模型协作 · 独立验收」主题和来源 Raw。本轮没有调用真实模型。
