# NEWSRAW02 删除后重新导入资讯

基线 27e407c。沿用本轮授权的 B 模式，GPT-6.2 Sol high 施工，GPT-6.2 Astra medium 独立验收。目标明确 0、跨两入口及知识库 2、涉及持久状态 2、用户已复现 1，合计 5。

- 已删除 Raw 的历史候选和已失败执行，在两个入口都能重新导入。每次重建重新采集来源，新建 Raw；现存 Raw 重复操作只关联当前记录。
- 两个入口按现有材料、当前草稿和成功发布的知识条目显示进度并提供可用跳转。只有正式确认成功才显示已导入知识库。
- 用卡兹克三模型文章在隔离环境从每日资讯导入、删除、从自动化再导入、再删除、从每日资讯再导入，验证当前草稿和正式入库后的两处显示。
- 施工者自查，独立验收者分别记录缺陷修复、批次整体结论和实际验证范围。
