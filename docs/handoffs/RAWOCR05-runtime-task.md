# RAWOCR05 微信图片 OCR 与精读执行链路

以《产品经理数据分析入门（一）》六图为验收样本。第一轮处理执行链路，第二轮处理入队前筛选、人工精读和六图重新导入验收。

第一轮验收基线为 `9afd003`。需求明确度 0，导入、精读及展示跨模块耦合度 2，外部 Provider 与本机图像解码不确定性 2，原图保留且解析结果可重算的影响范围 1，共 5 分。Astra Medium 规划及独立验收，Sol High 施工并先自查。

- 两个网页资料入口均保留原始下载字节。本机 Tesseract 接收可解码图像，验证简中和英文并区分缺少程序、缺少语言及转码失败。用实际动态图的第一帧核验。
- 本机不可用时，按配置保留人工处理或送入已有精读队列。
- Provider 接收从留存字节编码的 PNG 或 JPEG。区分下载、原图读取/校验、转码、Provider 网络、鉴权、图像输入及响应解析失败。用户可看到具体故障，日志不得泄露密钥或图片。
- 定向回归覆盖正常入口和异常，真实 Provider 验证与隔离回环测试分别记录。样本 Raw、原图哈希保持一致。
- 下一轮验证晚于正文 70% 的推广锚点、细长图与无 OCR 文字图表、极小图、模板重复和二维码上下文联合判断，以及跳过与失败卡片的手动精读。样本图 1、2 应完成精读，图 3 至 6 应显示明确跳过原因。
