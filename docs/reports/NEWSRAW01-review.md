# NEWSRAW01 独立验收

## 实际来源与两个入口

隔离目录仅复制每日资讯、目标候选和所需的历史保存记录。测试进程使用独立端口和不存在的 LLM 配置，清除继承的 LLM 凭据，全程未调用真实模型或更改正式 Raw。

- 对照用户下载的 HTML 和公开来源正常 GET 返回的 HTML，分别用 JSDOM 提取 `#js_content`。去空白后的正文均为 9,934 字符，SHA-256 均为 `6b85e5b652d68cec605a6fe49b81a8504d046355c8b33cc5a6a4c4b13f1acee5`，9 个原图资源路径和查询参数顺序一致。下载副本的 img.src 为占位图，原图地址在 data-src。
- 用 `node --import tsx` 调用产品 `acquireNewsMaterial`，分别直连样例和回放实页及 9 张原图，二者均调用本机 Tesseract 简中、英文 OCR。所得正文去掉图位转录并归一空白后与对照正文逐字相同。图 5 可检索“独立出一份方案”“定接口和验收标准”“GPT-6.2 Astra”“核实线上”；图 8 的四个表头、表中的“正在整理上下文”和最后一行的“外部运行”均命中。OCR 包含个别错字，图 5 的箭头关系仍需对照原图。
- Chrome 每日资讯 → AI 前沿 → 目标旧摘录 → 补采来源正文 → 查看 Raw。原 Raw ID 保持不变，正文修订升至 1，界面可见修改历史提示及来源图片入口。收件箱已入库条目也能打开同一份 Raw。旧网络实现遇验证页时，界面出现获取失败说明并保留重试按钮、原摘录和原 ID。更新后的公开客户端完成真实直连。
- 在第二个隔离目录只放当日报告及目标候选，去掉历史执行及确认状态，没有 Raw 和保存登记。从 Chrome 首页进入收件箱 → 确认入库 → 关闭自动整理 → 确认并入库，等待状态由“等待保存 Raw”变为“已入库 · 来源网页正文”。新建 Raw 与上一入口补采的 Raw 正文均为 15,203 字符，两次 SHA-256 均为 `f16a629b227ae4185b05d19095f284126b45ca9fe48d4fb200bcb53bebe2aa91`。两处各 9 个图件的实际内容均与元数据 SHA-256 一致。
- 指定来源为 [作者微信原文](https://mp.weixin.qq.com/s/gwj0xLNHPfToQnQJN7IkMA)。第三方全文、图片与操作临时数据没有写入仓库。
