- 核查 `git show --stat 17e244e 7b01402` 可见：`17e244e` 同步更新了 `tests/pipe01-ui.test.tsx`、`tests/run01-ui.test.tsx`、`tests/uifix02-ui.test.tsx`，但**遗漏了同步更新 `tests/uifix01-ui.test.tsx`**（其 L253、L416 点击侧栏 `自动化` 后未点击切换到「收件箱」标签页）。
- **结论**：该失败 100% 为 `17e244e` / `7b01402` 遗留的历史测试滞后，与 ENG02 工作区清理无关。按 ENG02 任务卡“排除”边界，施工者未修改该测试属合规操作，但批次整体 ENG02-06 仍必须如实裁定为 `FAIL`。
