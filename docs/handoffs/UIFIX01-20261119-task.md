## 2. 批次目标与交付项（U1-01 ～ U1-05）

本批为纯前端交互与样式修复，**不新增后端 API、不修改持久化数据结构、不发起真实外部模型或网页请求**。

### U1-01：全屏审核覆盖视图与子页面返回路径及面包屑修正
- **`app/App.tsx`**：
  - 第 155 行 `.breadcrumb`：补齐 `workflowId` 判定，使 `currentBreadcrumb = workflowId ? '更新与综合审阅' : reviewDraftId ? 'AI 知识整理预览' : pageTitle`。
  - 当处于可返回的覆盖视图或子页面（`Boolean(workflowId || reviewDraftId || page === 'news')`）时，将前缀“工作空间”渲染为可点击按钮 `<button type="button" className="text-button breadcrumb-back" ...>工作空间</button>`，点击按当前覆盖层级返回（有 `workflowId` 则 `setWorkflowId(null)`，否则有 `reviewDraftId` 则 `setReviewDraftId(null)`，否则 `page === 'news'` 时 `nav('home')`）；其余主导航页面保持纯文本 `工作空间`，`.breadcrumb` 文本内容保持 `工作空间 / ${currentBreadcrumb}`。
  - 第 161 行 `<AutomationPage>` 的 `onOpenDraft` 从 `{ nav('home'); setReviewDraftId(id); }` 改为 `id => setReviewDraftId(id)`，保持当前 `page === 'automation'` 上下文，确保审核结束后点击返回回到自动化收件箱。
  - 第 158 行 `<DraftReviewPage>` 传入动态 `backLabel`：`page === 'home' ? '返回工作台' : page === 'automation' ? '返回自动化' : page === 'wiki' ? '返回知识库' : '返回 Raw'`。
  - 第 162 行 `<NewsPage>` 传入 `onBack={() => nav('home')}`。
- **`app/pages/DraftReviewPage.tsx`**：
  - Props 增加可选属性 `backLabel?: string`（不设参数默认值，以便区分是否由调用方显式指定上下文返回文案）。
  - 第 233 行（`!view` 加载/错误兜底态）返回按钮使用 `{backLabel ?? '返回'}`；
  - 第 236 行（`view.input` 分支）向 `<KnowledgeMaintenanceReview>` 透传 `backLabel={backLabel}`；
  - 第 350 行（`outcomeMode` 分支）向 `<RawOutcomeReview>` 透传 `backLabel={backLabel}`；
  - 第 355 行（`view.maintenance` 分支）向 `<KnowledgeMaintenanceReview>` 透传 `backLabel={backLabel}`；
  - 第 368 行（默认分支）返回按钮使用 `{backLabel ?? '返回 Raw'}`。
- **`app/pages/RawOutcomeReview.tsx`**：
  - `Props` 增加可选属性 `backLabel?: string`，第 303 行返回按钮改为 `{backLabel ?? '返回'}`（不传时保持 `'返回'`，兼容直接挂载 `RawOutcomeReview` 的既有测试）。
- **`app/pages/KnowledgeMaintenanceReview.tsx`**：
  - Props 增加可选属性 `backLabel?: string`，第 32 行返回按钮改为 `{backLabel ?? (view.input ? '返回知识库' : '返回 Raw')}`。
- **`app/styles.css`**：
  - 新增 `.breadcrumb-back` 样式（继承字号与颜色，无多余内边距，悬停使用 `--accent` 与下划线）。
