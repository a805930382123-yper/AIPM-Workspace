# NEWS03 快消研报与数据洞察精选

日期：2026-11-08。规划基线：`7998f27`。本卡冻结用户已批准范围及必要验收；不是施工或验收通过证明。

## 目标与角色

将每日资讯的快消栏改为权威机构的快消/零售研报、消费者研究和经营数据洞察。普通新闻、秋收/农业消息不再入选。每日目标1～2篇，材料不足允许0篇，不凑数。AI栏沿NEWS02现状；保留来源摘录主动存Raw，后续用户沿既有审核进入Wiki。不调用付费产品模型、不安装依赖，不增加订阅推送、阅读状态、通用爬虫、OCR或新的知识流程。

评分需求0/耦合2/风险1/历史失败0＝3，A标准：目标明确；来源、选条、缓存及UI少量跨模块；仅兼容扩展期刊，旧Raw不改；没有本轮重复失败。Astra Medium规划，Sol High先审可执行性，Terra High施工，独立Sol High验收。主线程记录实际创建结果并统一提交。规划者只拥有本卡；不能自签产品验收。

依据：最新status与NEWS02任务卡及现行news代码；公开来源实测见[来源报告](../reports/NEWS03-20261108-sources.md)。当前fmcg用中国经济网/商务部、72h、5条和7日去重，ensure仅看当天栏是否存在，today失败回退不分内容类型；这些均需针对研报改动。NEWS02保存以URL独立收据幂等，Raw body严格等于excerpt，此不变量继续。旧日期文件、旧收据和已有Raw不迁移不重写。既有无关dirty、AUTO证据删除及未跟踪tests/news01-sources.test.ts保护，不纳入本批提交。

## 官方来源与材料边界

本批冻结Worldpanel与NIQ两家，贝恩/CCFA/毕马威后置。Worldpanel中文列表 https://worldpanelbynumerator.com/language/chinese-simplified ，详情只允许同host的/insights/。已测样例/insights/china-fmcg-retail-market-q3-2026（11月3日，2026前三季度）及/insights/china-shopper-report-2026-vol-1-cn（列表6月23日，正文报告发布6月16日，数据2025年至2026Q1）。列表日期与报告发布日期不同须区别，不用抓取日覆盖。NIQ目录 https://nielseniq.cn/global/zh/insights/consumer-packaged-goods/ ，详情白名单同host /global/zh/insights/analysis/ ，PDF白名单同host /wp-content/uploads/sites/9/ 的.pdf路径。已测详情 https://nielseniq.cn/global/zh/insights/analysis/2026/beverage-innovation-trends-and-growth-implications/ ，目录日期October 11 2026；实际PDF链接 https://nielseniq.cn/wp-content/uploads/sites/9/2026/10/Beverage-Innovation-Trends-and-Growth-Implications.pdf 。以官方目录→详情→PDF链接发现链为入口，已测饮料报告4,063,047字节、14页且可抽中文。启用来源须本机Node实读，不用搜索摘要或硬编码文章替代持续发现。

沿现有fetch限时、响应大小、手工重定向及逐跳白名单；只加入实际需要的官方host和路径。不接收用户任意URL，不抓登录或付费内容，不执行网页脚本、不安装依赖。每家最多取4个相关候选详情；NIQ最多下载2个最新候选PDF，每份10MiB上限、最多抽前20页、输出有界原文摘录；沿已装pdfjs-dist提取文字，不做OCR，页面超过抽取范围明示节选。逐跳仅允许冻结NIQ官方资产域与PDF路径，不接任意外链。不修改既有Raw上传解析器。源列表发现候选后获取对应详情正文；列表页标题、导航、下载表单、cookie文字和SEO描述不得充当正文。报告仅有表单或无法读取正文/PDF文字时跳过并记录来源未取得正文，不把空壳页算成功。NIQ只有短简介时必须实际取得PDF正文才入选；PDF摘录标明文字提取、页码范围、非全文，保留官方详情URL及PDF来源URL。官方详情自带实质性摘要可用，但标明“官方报告介绍摘录，非报告全文”；直接研究文章正文标明“官方研究正文摘录，非全文”。不把AIHOT摘要标签用于研报。

材料必须同时满足官方允许来源、消费品/零售相关、研报/消费者研究/经营数据洞察属性；普通活动、获奖、机构宣传、新闻汇总与农业收储排除。不凭标题关键词造内容。截取有界原文段落，可做既有HTML文本清理；不得拼写推断、模板分析或补数据。

字段最小扩展：NewsItem可选research元信息（具体命名施工可定），包含材料类型、dataPeriod:string|null及可选PDF来源URL/抽取页范围；dataPeriod仅接受来源独立标注的统计期、统计周期、数据截至、调查时间或调研时间等直接口径文本，不从经营叙述推断或汇总年份；null代表未能可靠识别，不代表原文没有提供，显示“数据时期：请以原文为准”。不从发布年或标题猜测，不把发布月份当作数据覆盖期。样本量/地理范围/研究方法等口径仅展示来源实际声明，可留在原文摘录中，不为字段完整而补造，不将地理覆盖或发布日期当样本量。publishedAt仍只存来源真实发布日期；fetchedAt/期刊日期不代替发布日期。报告摘要与正文摘录用明确材料等级区分，沿现有evidenceKind及新增研究元信息表达，无需改变AI条目结构。

## 选条与呈现

新快消固定365日发布窗口，排除未知、未来日期；上海日期解析沿已有实现。窗口表示近期发布，不保证数据覆盖今日。只展示明确的真实发布日、数据时期和官方来源，不宣称仍具有当下预测效力。按发布时间降序，再规范URL及既有稳定平局键排序；规范URL/完整标题去重沿NEWS02。历史损坏文件按现有history方式独立记录，不因某个旧期损坏把今天全部来源误报失败。新研报在过去365个上海日期的研报精选中已展示则不再选，最多2篇；可枚举已有期刊比较，不必逐日读取365个空文件。不新增“已读”跟踪，不循环旧条目充数。AI保持24h、3条、7日去重及现有优先排序。

fmcg新版本有合格材料时为source_only，真实空/失败仍为对应状态；即使全局AI开关打开也不创建或调用Provider；直接阅读官方材料。不显示未生成的模板“为何值得关注/可能影响”占位，不伪造分析。AI栏原Provider行为保持，但本轮验证禁真实调用。首页与资讯页栏目名称“快消研报与洞察”，说明“近365日发布，每日精选最多2篇；报告非每日更新”。删除旧不足3条及商务部渠道不足提示。0条显示“暂无新的可核验研报”，部分来源失败与全部失败沿真实状态区分；不足2条不算失败。

## 当天缓存和旧资料过渡

新增可选栏目内容版本，例如NewsSection.contentVersion='research-v1'；旧字段缺省表示旧新闻，schemaVersion1继续可读。ensure只对当天不带新标记的fmcg升级一次，不能因当天旧栏ready就跳过；ai栏保留原值与状态。新运行/空/失败栏均带标记，重复或并发ensure不重复抓取，重启仍按已有中断/重试契约处理。GET today发现当天旧栏时只读投影为待更新，不先把旧新闻显示为研报；GET不写盘、不抓取。

过渡使用同一日期JSON的可选legacyFmcg字段保存完整旧fmcg栏，然后以新版running替换sections.fmcg，在既有queue内一次原子写入；旧栏分析、来源、条目和状态完整保留。失败或中断重试不再次覆盖legacyFmcg。读边界校验可选旧栏；旧日期文件不改写。当日升级前新闻显示在独立折叠区“升级前快消资讯（历史）”，绝不混入新研报主栏；过去日期的旧栏也明确标为旧版新闻。

today的fmcg失败回退仅允许research-v1，不能从旧新闻回填。回退仍显示真实所属期刊日期与原发布日。旧当日栏可读、可主动保存Raw：saveRaw按date/section/itemId在当前栏和legacyFmcg中定位，采用实际命中栏的可保存状态；savedRaws投影包括旧栏。接口不增加客户端正文、Raw ID或新的保存身份。若同ID两栏重合，当前条目优先且旧收据仍按规范URL复用。旧收据不重写；已有Raw不改。新保存研究dataPeriod、材料等级及PDF来源URL/抽取页范围（如适用）写入extractionNote/收据输入快照，body仍逐字等于excerpt，不把元信息拼进正文。

本设计只有当日可选旧栏保留，不做通用版本历史系统；备份现有state根自然覆盖。若实现发现必须改Raw存储schema或审核门禁，停止该扩展并交主线程裁决。
