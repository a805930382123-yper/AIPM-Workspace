# LLM-Wiki 2A-3 复核工作台与整批验收

基线 792bdba。用户逐阶段授权最后阶段 Step 5–6。B 模式：Sol high 施工与自查，Astra medium 独立验证，主 Agent 统一提交。以真实隔离服务和浏览器验证交互，正式资料及外部模型均不参与测试。

| 项目 | 签收口径 |
|---|---|
| 复核工作台 | 从正常导航进入单抽屉，四个内部胶囊页展示待复核、30 天内到期、历史未核验与真实索引状态。一次聚焦最多五项，显示原因、系统推断/提醒标识；无自动裁定或嵌套抽屉。 |
| 读时操作 | Wiki 详情与 Wiki 引用卡可见时效徽章，显式一键确认仍有效；暂缓与调整周期可在复核流程中完成。核验成功、冲突、失败均给出真实反馈。 |
| Lint 与权限 | 现有 Lint 界面显示时效汇总；受限页面不进入列表、计数、引用或操作。核验不改变 Raw 正文、Wiki 正文及 UTF-16 引文位置。 |
| E2E 与回滚 | 真实浏览器、隔离库验证触发→提醒→人工处理、窄屏与键盘、禁用开关后旧交互可用且既有事实保留、重启恢复与删库重建。冻结 25 问复跑对照 50 条上下文；类型、全量测试与生产构建通过。 |
| 结束条件 | 独立区分缺陷返修、2A-3 与整批 2A 裁决，记录命令、产物指纹或提交标识。 |
