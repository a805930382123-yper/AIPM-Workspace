## 2. 无环结构与关键红线核对

- **DAG 依赖拓扑**：
  - `services/wiki/commits.ts` -> `{commit-types.ts, commit-service.ts}`
  - `services/wiki/commit-service.ts` -> `{commit-types.ts, commit-freeze.ts, commit-executor.ts}`
  - `services/wiki/commit-freeze.ts` -> `commit-types.ts`（不导入 `../search/duplicates.ts`、`commit-executor.ts`、`commit-service.ts`）
  - `services/wiki/commit-executor.ts` -> `commit-types.ts`（不导入 `commit-freeze.ts`、`commit-service.ts`）
- **门面等价性**：`services/wiki/commits.ts` 仅重导出原有 4 项运行时符号（`CommitError`、`pendingRawCommit`、`scanWikiCommits`、`WikiCommitService`）与 7 项类型符号（`CommitPhaseName`、`CommitPhase`、`CommitStatus`、`CommitSnapshot`、`CommitManifest`、`QuestionCommitManifest`、`KnowledgeCommitManifest`），零内部辅助函数泄露。
- **语义红线保持**：
  1. `executeCommitManifest(deps, queue, input)` 与 `reconcileCommitManifests(deps, queue, listManifests)` 共用 `WikiCommitService` 实例传入的唯一 `private readonly queue = new SerialQueue()`。
  2. `executeCommitManifest` 内保留闭包变量 `let manifest` 与内部 `save`/`markPhase` 就地更新语义，确保 `F04-09` 错误 `details` 携带最新 `phases`/`status`；保留 `let currentPhase: CommitPhaseName = 'source'` 初始化与 `await save({ status: 'committing' })` 顺序，未触发 `no-useless-assignment`。
  3. `commit-executor.ts` 与 `commit-service.ts` 使用顶层 `import type { RawStore } from '../raw/store.ts'` 替代内联动态类型导入。
  4. `confirmQuestion` 原样保留 `requested.sort()` 原地副作用；`payloadDigest` JSON 对象字面量字段顺序及 `freezeMaintenanceSnapshot` 原地填充 `snapshot` 语义完全一致；`findDuplicateCandidates`（`../search/duplicates.ts`）仅保留在 `commit-service.ts`。
