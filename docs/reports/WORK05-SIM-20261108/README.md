# WORK05 合成试验材料

这两周的 12 条问答是为演练写的合成记录。人、业务数字、门店编号、报表文件及回答结果均为虚构。材料用于测试数据形态和产品操作。

## 演练假设

| 项目 | 本轮假设 |
| --- | --- |
| 来源 | 每周整理一次智能参谋的用户提问及当时回答。每条独立标识一个问答，附件不在本轮导出范围。 |
| 目标 | 所有新材料进入同一已有产品事项「【合成】智能参谋能力缺口」，用于排查报表、数据时点、口径及澄清行为。 |
| 使用 | 在事项详情看到新增 Raw 后，由人选择资料。每轮上限为 8 条，两周材料可分轮筛选。 |
| 试点投递 | 预期由获批来源交付文本事件到固定本机目录。正式来源、时段、留存期限和权限仍待冻结。 |

## 验收预期

| 检查 | 操作 | 可观察结果 |
| --- | --- | --- |
| S1 样本 | 核对两批 JSON 和下列变体 | 12 条正文含合成标识，事件 ID 唯一。重复、冲突和缺字段各有独立可复用输入。 |
| S2 人工链路 | 先建一条已有完成轮次的合成事项，分两周各粘贴并手动关联 6 条 | 逐条回读及磁盘正文匹配。建议计数先 6 后 12。刷新后点击建议只聚焦资料选择，演练期间模型请求 0。 |
| S3 自动投递 | 在未来的接收入口投递、重复、重启和恢复 | 本轮未运行。后续按 [WORK05 任务卡](../../handoffs/WORK05-20261107-task.md) 验证。 |

| S3 边界样例 | 预期 |
| --- | --- |
| 正常投递 | 获批来源提供 A1，保存一条原文 Raw 并关联固定事项，满足条件时出现继续提示。 |
| 完全重复 | 用同一个 A1 逐字重投。保持一条 Raw 和一处关联，复用原 Raw ID。 |
| 同 ID 改正文 | A1 的等待时长由 30 秒改为 45 秒，ID 和标题相同。显示冲突，保留原材料和关联。 |
| 缺正文 | 提供 ID 和标题，省略 `body`。显示拒收原因，无 Raw 或关联增加。 |
| 关联前中断 | 模拟 Raw 已保存、关联尚未完成。恢复时使用原 Raw 补关联。 |
| 停服留存 | 用 B6 作为独立停服样本，由来源在停服时留存。期间零处理，复机后按保留规则处理一次。 |

两次报表失败采用不同错误码，成功对照缩小了范围或降低了粒度。可以据此设计复跑，也可以区分数据尚未到齐、指标口径不同和提问本身模糊。实际发生频率、人工漏项和使用价值仍需观察真实流程。
