# LLM-Wiki 1A-2 派生索引与结构切块

依赖已通过的 [1A-1](LLMWIKI-1A-1.md)。本轮仅授权原提示词 Step 1 和 Step 2。主 Agent 负责范围与同步；gpt-6.2-sol high 负责施工、自查及施工报告；自查通过并停写后，gpt-6.2-astra medium 对实际代码独立验收，写审查报告。

| 验收项 | 检查方法与预期 |
|---|---|
| 可重建存储 | 隔离数据根实建 meta、pages、chunks、chunks_fts 四表，核对版本锁、预留列与索引路径。删库重建后内容、哈希、检索结果一致。 |
| 一致性 | 启动按正式 Markdown 文件哈希对账，版本变化全量重建。单页增删改同步无过期块及 FTS 孤儿；索引故障可观察，正式文件完好。 |
| 原子替换 | 临时库构建期间持续读取旧库；成功后可读取新库，失败可保留可用索引；验证 Windows 文件替换。提供手动重建入口和计数耗时。 |
| 切块 | 识别真实 Wiki 的标题和事实／推断分区。分区间零合并、零重叠；无标题回退、同父短段合并、长段拆分。150 软下限、含重叠 1,200 硬上限、约 100 重叠。每块按正文 UTF-16 坐标逐字切片一致。 |
| 证据 | 记录驱动、千页实测、25 问分类及 B 类漏题证据状态。独立区分阶段及 Batch 1A 整体结论。 |

检索权重、同义词和生产检索／写入钩子按 1A-3 计划推进，25 问双引擎评测在 1A-4。保持真实库只读，使用隔离数据验证。共享区内其他工作的差异单独保留。
