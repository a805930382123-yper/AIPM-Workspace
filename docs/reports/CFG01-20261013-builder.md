## 实现

- 设置页可编辑 Base URL、模型 ID 和 password API Key；明确保存后密码框清空，空 Key 表示保留既有值。连接测试需单独点击；清除需浏览器确认。环境变量覆盖显示只读说明，连接测试仍可由用户显式触发。
- 服务端配置仍使用项目 `.env.local`，只允许服务端环境变量 `FMCG_LLM_CONFIG_FILE` 指向隔离配置。读文件仅把 `ENOENT` 当作缺失，其它读取错误会失败关闭。保存与清除串行执行、校验进程内 HMAC revision，并通过同目录临时文件和 rename 原子替换；写入失败会清理临时文件并返回通用错误。新增键只更改三项 FMCG_LLM 配置行，保留其它行、注释及换行；无末尾换行时为新增配置补上边界。
- 配置摘要只返回已校验的 URL/模型、固定 Key 掩码、Key 是否存在、来源、revision、进程内 writeToken 和环境锁状态；不会回传 Key、长度/首尾片段或裸 SHA。部分环境变量仍按既有逐字段优先级覆盖文件；完整环境变量沿用原行为，不读取本机文件。任何非空覆盖都会锁定保存/清除。
- 配置 API 校验本机 Host、可信 Origin、JSON、`X-FMCG-Config-Token`、revision、确认字段和严格字段集合。连接测试仅发送固定英文探针，15 秒/4096 字节上限；对解析后的 JSON 键和值或纯文本扫描已知凭证，响应仅包含安全结果和耗时。
- 每个请求独立解析当前有效 Provider 并以 AsyncLocalStorage 绑定其快照。长任务继续持有启动快照，后续请求读取新配置；不使用全局 Provider 交换。
- 配置文件读错误不再阻断服务启动或普通 HTTP 请求；只有明确读取配置摘要/保存/清除/连接测试，以及实际需要 Provider 的 AI 入口才解析配置。连接测试直接按请求加载有效配置。完整环境配置继续不依赖本机文件。
- 安全摘要和运行 Provider 均把有效环境 Key、本机旧 Key、当前/新 Key 纳入可读字段检查；完整环境配置时本机文件读取仅作可选的凭证识别，读取失败不会影响环境配置。
- 新 API Key 使用可逆的双引号转义写入本地 env 行，解析兼容既有单/双引号值；用包含首尾引号和反斜线的测试 Key 验证写入、读取及最终 Authorization 值一致。
- 保存用 revision 校验时读取的同一字节快照生成新文件；临时文件写完后、rename 前复核原配置字节，发现外部修改返回 409 并清理临时文件。此检查不声称提供文件系统原生 CAS。
- 非成功 Provider 响应也经过 4096 字节流式预算，超限即取消读取并返回明确错误；普通 401 继续安全脱敏。Base URL 在规范化前后检查已知凭证，并拒绝字面空/非空 query 与 fragment。窄屏样式保留 Settings 按钮。
- Settings 的首次读取、重新读取和编辑共用请求 generation；每次输入变更会让旧 GET 作废。组件定向测试覆盖初始/重新读取迟到响应不覆盖用户输入。
