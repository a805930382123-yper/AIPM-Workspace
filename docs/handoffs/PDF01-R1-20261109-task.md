## 最小实现合同

1. 复用 AssetStore 原件保存及SHA核验。pdfjs-dist 6.4.299 提取每页真实文字并渲染整页（包含扫描嵌图和矢量图）；已装 `@napi-rs/canvas` 1.0.10 允许声明同版直接runtime依赖，不引入外部CLI/OCR平台。逐页释放画布/页面资源，页面尺寸有界且不裁切，62页不同时常驻全部bitmap。
2. 扫描PDF可导入：只有服务端验明真实PDF、原件保留且确实无文字层的分支允许Raw空body；普通粘贴/非PDF空文件仍拒绝。不可注入提示占位字或AI OCR到原文；保留原页文字含空页的映射，既有非空Raw正文与引用偏移兼容。扫描Raw旧整理入口明确不可用并指向本轮页级读取。
3. 独立 `state/pdf-pages/<rawId>/` 保存页manifest、页图和理解结果，绑定rawId/assetId/原件SHA/页码/渲染及提示版本；AI结果与文字层分开，不能充当原文引用。失败保留原件与已成功页；没有全页完成不得宣称整份已读。
4. 最小API以 `/api/raw/:id/pdf` 为前缀：GET状态/页目录、GET `pages/:page` 页文字与结果、GET `pages/:page/image` 图片；POST `prepare` 本机渲染，POST `understand` 显式模型启动，POST `retry`/`cancel` 恢复或取消。可以将prepare与首次本机页读取合并，但所有GET绝不触发Provider。施工如需调整命名先发精确DTO供UI共用，不另建通用任务平台。
5. 理解采用每页一请求，传真实页图和该页文字；至少分别显示页面内容/图表说明、推断与疑问，标识AI理解；空页也有对应页结果或明确空白判定。顺序执行、每页成功即保存、实际请求前计数；进度显示完成页/总页，取消及失败可见。显式重试仅未完成页，重启无自动调用；重启可能重发尚未落盘的一页如实说明，不承诺网络exactly-once。完整性/Provider身份/提示版本变化不得静默拼接旧结果。
6. `LlmCompletionRequest` 新增可选本地图像输入，由现OpenAI兼容适配器构建user content数组（文本+data URL image_url）；无图时保持原string请求。不接受任意远程图URL抓取、不丢图后降级text。未知模型图像能力由实际响应决定：不支持/坏格式失败可见，不伪成功。复用现超时、取消、秘密输出和来源外发门禁；图像像素无法靠文本秘密扫描证明无敏感信息，显式启动需说明将发送所选PDF页面图像。Meeting受限来源仍拒绝。
7. Raw最小页面面板：原件链接、当前页码/页图/文字层/AI结果，紧凑页导航、显式启动与单一进度、失败继续/取消。结果点击定位同一原件同一页，不把AI文本写入Raw。默认不铺满62页图片。文件导入保留现有恢复合同，失败仍告诉用户原件是否保留。

## 必验与命令

- P1 真实混合PDF（文字、无文字扫描图、矢量图）：导入后原件SHA字节不变；页数/空页/文字映射准确；图像实际非空且亲看扫描与矢量内容；纯扫描Raw保存空正文，其他空输入不放宽。
- P2 62页合成：所有页真实渲染、页号1..62和结果均可枚举、顺序资源使用；不得截前N页后报全读。
- P3 本地HTTP Provider抓取实际JSON并解码图像，逐页SHA与渲染PNG一致；旧无图请求仍string；至少一条经实际server/index入口+TEMP配置，防止路由Provider接线漏测。
- P4 中页失败/坏JSON/Provider拒图、取消迟到、重启显式继续：已完成页保留，失败不显示completed、无自动追加请求、原件不变；源/身份不匹配拒复用。持久化失败不能假成功。
- P5 私密/Meeting/已知凭证文本与输出门禁、读取越界页/未知Raw、普通text问答/导入不回归。不得宣称图像秘密检测或真实模型能力已测。
- P6 实际Chrome/Edge隔离完整App：导入扫描及混合PDF→页图→显式理解→页结果定位，失败继续与刷新无重复模型；截图至少入口、扫描页图、矢量页图+结果、失败状态。独验亲看截图。
- P7 定向 `node --import tsx --import ./tests/support/css-stub.mjs --test tests/pdf01*.test.ts tests/pdf01-ui*.test.tsx`（按实际文件校准）、原file-import/Provider相关回归；`npx tsc -b --pretty false`与空envDir build。全仓现已有损坏测试，不挪用旧763全绿；记录本轮实际失败并以产品+新增测试独立类型检查、必要回归明确受验范围，不擅修无关损坏文件。

施工交接含最终SHA/命令/日志/截图/未测限制；独验可复用同版可信非关键重复记录，但须独立跑核心及核实际图像。发现范围内失败交施工修，不改产品。分别裁决本轮缺陷及第一轮整体；通过即停止，第二轮未授权不开工。

## 开工接口收敛（施工前确认）

最终目录采用 `state/raw-pdf`。GET `/api/raw/:id/pdf` 返回页目录（含每页textStart/textEnd，空页null）、imageUrl及job；GET image本机按需渲染。POST `understand`兼任首次与显式继续，POST `cancel`；不另建prepare/retry，GET无Provider。任务逐页渲染再理解，导入不同时渲染62页。所有模型范围为整份PDF未完成页，UI如实告知。

`extractBody`仅file-import显式allowPdfWithoutText，通用parseFile保持扫描拒绝，避免影响新闻等现消费者。追加后端 `services/llm/jobs.ts` 仅空扫描旧整理早拒绝；UI导入“保存并生成”遇空扫描保存后不调用旧整理，提示进入页级图文。UI类型复用app/api.ts，不创建当前不存在的app/types.ts；允许 `tests/ui.test.tsx` 仅旧“扫描不支持”文案断言随本轮实际支持变更。依赖已在本机createCanvas实出PNG，仍需实际PDF渲染验收。
