### U2-03：首页「周期回顾」修改日期后的空白面板反馈与起止日期校验
- **`app/components/PeriodReview.tsx`**：
  - 新增 `loading` 状态（初始为 `true`）：在 `load(a, b)` 发起请求前置 `loading = true`，`finally` 中若 `current === generation.current` 置 `loading = false`；在 `change(fn)` 中置 `loading = false` 并保留 `generation.current++`、`setData(null)`、`setError('')`。
  - 计算 `const invalidRange = Boolean(start && end && start >= end);`。
  - **关键既有测试契约（`tests/lifeos-l6-review-ui.test.tsx`）**：`change()` **不得**在修改 `<input type="date">` 时自动调用 `api()` 发起网络请求（该测试断言修改日期并点击 `刷新回顾` 后总请求数严格为 `2`）；按钮文本必须严格保持 `'刷新回顾'`。
  - 在 `load(a = start, b = end)` 开头增加守卫：若 `a && b && a >= b`，不发请求，置 `setLoading(false); setData(null); setError(''); return;`。
  - 仅在 `invalidRange` 时禁用「刷新回顾」按钮（`disabled={invalidRange}`），防止请求期间锁死用户手动重试，同时拦截非法日期区间提交。
  - 当 `invalidRange` 为真时，展示 `<p className="form-error" role="alert">开始日期需早于结束日期。</p>`；当 `!invalidRange && !error && !data` 时，展示 `<p className="review-status-hint" role="status">{loading ? '正在读取周期回顾…' : \`日期范围已调整为 \${start} 至 \${end}，请点击「刷新回顾」加载该周期数据。\`}</p>`，彻底消除修改日期或加载中的空白面板。
- **`app/home.css`**：
  - 补充 `.period-review .review-status-hint` 样式，确保提示排版与面板一致且移动端无溢出。
