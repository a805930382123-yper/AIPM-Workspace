施工使用 TypeScript AST 按原函数和顶层语句提取，再通过 esbuild 的 TSX 转译及空白归一化核对。临时命令 `node .scratch/fe04-equivalence.mjs` 返回 18 项全部一致：9 个独立函数体、RawPage 的全部状态/动作/effect 顺序、综合打开事件体、RawPage 完整渲染 JSX、RawDetail 全部状态/动作/effect 顺序、4 个翻译展示派生表达式、RawDetail 完整渲染 JSX、两份 props 类型以及无环运行时依赖图。临时脚本和生成日志不进入 Git。

具体边界核对：

- 所有 `useState`、`useRef`、`useEffect` 的初始值、调用顺序、依赖数组和 cleanup 原样迁移。没有为清零原有 lint 告警调整 effect 行为。
- `key={selected.id}` 保留；`initialOriginal` 默认值、引文 rawId/hash/位置检查、PDF 与 meeting-only 条件保留。详情 hook 与原详情仍属于同一个 keyed 组件实例。
- `startAi` 与 `generateImported` 在请求前捕获的 navigation/selection 世代值、错误携带 jobId 时的读取、`onJobStarted` 参数及 `onRefresh` 顺序逐句一致。恢复操作的 generation 校验和不重新生成语义未改变。
- 导入 API path/method/payload、精确正文、`onCommitted` 优先于生成和导航、部分提交处理、保存后生成失败时沿用同一 Raw 重试，以及正文版本冲突核对均保留。
