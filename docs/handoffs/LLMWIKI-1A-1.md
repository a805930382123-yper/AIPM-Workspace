# LLM-Wiki Batch 1A 检索改造

本轮授权 1A-1。主 Agent 负责接口和交付，gpt-6.2-sol high 施工并自查，gpt-6.2-astra medium 独立验收。每阶段结束后汇报，后续阶段等待授权。

| 阶段 | 内容与门槛 |
|---|---|
| 1A-1 | 抽查 3–5 篇真实 Wiki（含长页），核对分区、引文坐标、正式写入路径及调用方。Node 22 驱动通过 WAL、NORMAL、外键、FTS5、加权 BM25 和 strict 检查。单事务写入 1,000 页、6,000 块及 FTS <1,500 ms，20 次随机查询平均 <50 ms。原生驱动未达标则锁定备选并重测。 |
| 1A-2 | 派生索引存储、版本与哈希对账、增删改及原子重建。事实与推断硬隔离，所有块的 UTF-16 偏移均能还原原文。 |
| 1A-3 | 中文分词、行业同义词、块召回和业务接入。保留现有数组 API，另供详细结果接口。Prompt 在用户选页内取块。保留权限、引用及 48,000 / 12,000 字符预算；故障自动降级。 |
| 1A-4 | 隔离全量检查、真实 Markdown 流程千页基准、长页九点定位、25 问双引擎分类评测及回滚。 |

1A-1 的施工文件归施工 Agent，验收报告归审查 Agent，任务卡与状态归主 Agent。驱动基准采用临时合成数据，真实资料只读勘察，报告仅记录结构。每轮记录驱动、千页实测、25 问各类及 B 类漏题的证据状态。
