## 冻结接口与边界

Meeting 按规划 snake_case 存储，`schema_version:1`、服务端 UUID `meeting_id`、`revision`、时间和策略由服务端维护。未来 imports/raw_links 等结构只存空数组/空指针；不实现未来流程。单会议记录一个完整提交单位。

HTTP 最小契约（详细返回结构在交接记录）：

- `GET /api/meeting-catalog` → `{schema_version,revision,types,tags}`；类型/标签条目 `{id,name,active}`，稳定 ID。
- `POST /api/meeting-catalog/types`、`.../tags` → `{baseRevision,name}`；`PATCH .../types/:id`、`.../tags/:id` → `{baseRevision,name?,active?}`。目录 revision 与去空白名称去重；不提供物理删除。
- `POST /api/meetings` → `{requestId,title,meeting_date,meeting_type,...允许元数据,confidentiality?}`；requestId 为合法客户端 UUID 幂等键。响应会议详情包含 `capabilities`；服务端会议 ID 不接受客户端指定。创建默认 cloud_index，策略修改独立操作。
- `GET /api/meetings` → `{items}` 摘要，禁止 imports/原文/工作副本字段；`GET /api/meetings/:id` → 详情。
- `PATCH /api/meetings/:id` → `{baseRevision,...允许元数据}`，拒绝所有策略、正文、来源和服务器字段；`DELETE .../:id` → `{baseRevision,confirm:true}`。
- `PATCH /api/meetings/:id/policy`：baseRevision 必须；只能保持/提高 confidentiality。允许独立 storage_mode 与明确授权操作，具体确认字段 builder 先报告后固定给验收。external_ai_authorized 永远 false，明确请求 true 拒绝。Internal/Sensitive 本地保存必须专门确认；Restricted 转换需确认清空非允许元数据，未确认不改。策略只变元数据，不导入/登记/调用 AI。
- M01 `canImportMinutes/canRegisterRaw/canUseAi` 全 false，给出实际未交付/策略拒绝原因；不装配纪要、Raw、AI 的半成品路由。

字段/URL/日期时间/枚举/UUID/长度/集合上限校验放服务层；合法 HTTPS 无凭证或控制字符，空链接可用。默认八类型只初始化一次，标签初始为空。旧停用目录引用仍可读、显示和保留，不能用于新选择；改名不改 ID。目录和会议损坏必须报409，不隐藏、覆盖或自动重建。ID/目录/文件路径不跟随链接逃逸；明确存储5xx，不回显文件原始错误或用户正文/链接。

已固定 policy 请求：`{baseRevision,confidentiality?,storage_mode?,local_storage_authorized?,raw_transfer_authorized?,external_ai_authorized?,confirm_local_storage?,confirm_raw_transfer?,confirm_restricted_metadata_clear?}`。三个确认字段为 boolean。Internal/Sensitive 启本地或提高等级仍保留本地，必须本次明确 `confirm_local_storage:true` 与 `local_storage_authorized:true`；Public 切本地无需此授权。Raw 授权仅有效 Public/Internal 本地策略可保留，必须独立 `confirm_raw_transfer:true`；M01实际登记能力仍关闭。升等级清 Raw 授权。Restricted 升级需要清元数据时，未确认先409，details只列 `metadata_to_clear` 字段名和待处理副本数量，不回显值；确认后清非允许元数据并设cloud/三false。目录变更返回完整最新目录；创建新201/重试200，响应flat详情加reused；详情/更新/策略flat详情加capabilities，删除200 `{deleted:true,meeting_id}`。

幂等创建将 requestId 和规范化原始创建输入的 SHA-256 摘要与会议同文件原子持久化，不另存原始私密字段；同键不同输入返回409。更新/删除 revision 与目录校验在串行边界内；重试无重复对象。同目录重启仍可读取。新旧备份兼容，仅把 meetings 加入现有白名单，不弱化路径/大小/摘要/联接保护。此摘要约定用于避免升级 Restricted 后 creation 内仍保留已清字段。
