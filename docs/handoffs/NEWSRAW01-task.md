# NEWSRAW01 资讯原文入库

用户授权更新资讯共用保存、网页图文读取和候选收件箱处理，以「卡兹克分享 Claude、GPT、Gemini 三模型协同调度方法」实测。从 main 的 298dcfca 开始。B 模式采用 GPT-6.2 Astra medium 规划及独立验收、GPT-6.2 Sol high 施工。评分 5 分（目标清晰 0、跨模块 2、历史 Raw 完整性 2、已复现一次 1）。

- 两个资讯入口在明确保存时获取同一来源材料，正文、图片位置、来源和获取结果可核对；报告区分发布页与全文。
- 用上下文筛选图片。信息图保留原图及可核对的 OCR 转录。
- 缺正文或关键图片失败可见、可重试。部分材料需显式确认，默认暂停生成草稿。
- 旧摘录可显式补采，保留人工修订及链接关系。
- 独立验收在隔离目录验证两个入口、失败反馈和指定实际来源，分别裁决局部修复及整体通过情况。实际来源访问受限时记录具体结果。
