2. 单来源 Source 与新提取页采用该来源初判；页级已有人工修改拥有优先权，保存、刷新、合并/更新、明确确认后不被模型结果或默认值重置。无 AI 的新建缺省 D；手工明确选择仍保留。人工改等级不等于自动 reviewed/verified。
3. 更新从已审输入草稿继承来源等级，已有目标 Wiki 的等级保持；补建 Source 使用该 Raw 已审等级。综合在现有综合请求中按 Raw ID 给出每个输入来源等级，已有人审来源等级优先；新综合页采用实际来源等级的最低等级作为保守初值（A→B→C→D），这是不自动拔高多来源可信度的最小派生策略，必须可人工修改。无需逐事实权重、评分体系或新通用框架。
