### U4-01：知识库 Markdown 原文「选段提交 Audit」交互顺畅化
- **`app/pages/WikiPage.tsx`**：
  - `WikiDetail` 向 `<AuditPanel>` 新增可选属性 `onClearAnchor={() => setAnchor(null)}`。
  - `AuditPanel`（第 417-450 行）新增 `pendingAnchor`、`focusCommentRequest` 与 `commentRef = useRef<HTMLTextAreaElement>(null)`（绑定到反馈 `<textarea ref={commentRef} ... />`）：
    - 当 `item.id` 改变或 `selectedAnchor === null` 时同步清空 `pendingAnchor`；
    - 当接收 `audit:create-paragraph` 事件且含有效 `anchor` 时：
      - 立即设置 `setExpanded(true)`、`setPendingAnchor(anchor)`；
      - 若 `comment.trim()` 已非空，直接调用 `void create('paragraph', anchor)`；
      - 若 `!comment.trim()`，**不直接报错**，清除既有错误 `setError('')`，并递增 `focusCommentRequest` 以便在展开渲染后通过 `useEffect` 执行 `commentRef.current?.scrollIntoView?.({ block: 'nearest' })` 与 `commentRef.current?.focus()`。
    - 设 `const activeAnchor = pendingAnchor ?? selectedAnchor;`：
      - `.audit-create` 顶部在 `activeAnchor` 非空时展示 `<div className="audit-bound-anchor" role="status"><span>已绑定选中段落：「{activeAnchor.text.slice(0, 80)}{activeAnchor.text.length > 80 ? '…' : ''}」</span><button type="button" className="text-button" onClick={() => { setPendingAnchor(null); onClearAnchor?.(); }}>改为整页 Audit</button></div>`；
      - `.audit-create` 操作区：当 `activeAnchor` 非空时，渲染 `<button type="button" className="primary-button" onClick={() => void create('paragraph', activeAnchor)} disabled={busy || !comment.trim()}>提交选中段落 Audit</button>` 与 `<button type="button" className="secondary-button" onClick={() => void create('page')} disabled={busy || !comment.trim()}>提交整页 Audit</button>`；当 `activeAnchor` 为空时，保留 `<button type="button" className="primary-button" onClick={() => void create('page')} disabled={busy || !comment.trim()}>提交整页 Audit</button>`；
      - 当 `create('paragraph', ...)` 提交成功后，自动清空 `pendingAnchor` 并调用 `onClearAnchor?.()`。
- **`app/wiki.css`**：
  - 新增 `.audit-bound-anchor` 与 `.audit-create-actions` 样式，保证绑定提示与按钮在桌面/手机视口下对齐、不溢出。
