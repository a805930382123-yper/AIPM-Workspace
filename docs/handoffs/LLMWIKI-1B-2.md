基线 4b4081a，本次授权 Step 3–5 及对应离线回归。按 B 模式由 gpt-6.2-sol high 施工自查、gpt-6.2-astra medium 独立验收，主 Agent 负责范围、交付记录及提交。全程仅用合成数据和回环服务测试，阶段完成后停止。

| 验收项 | 核验口径 |
|---|---|
| 向量缓存 | 同版本单位向量载入内存；新增、编辑、删除、补算、模型变化及全量重建后与 SQLite 一致。白名单在点积前过滤，显式空选页返回空，Top-30 按分降序。 |

| 业务接入 | 默认 hybrid，故障依次降至 sqlite_fts、legacy_scan，返回实际引擎和原因。保留原数组接口、48,000 / 12,000 字符及每页上限；问答、提取、巡检、维护、PDF 草稿、Prompt 的权限和上下文边界不变。 |
| 证据与保护 | 在实际入口捕获选页 Prompt 上下文；纯向量引用按 Wiki 正文 UTF-16 逐字验证。证据或权限发生变化时拒绝过期依据。验证禁用、无向量、超时、错误、损坏、显式回滚及正式保存。 |
| 交付 | 施工自查后冻结，独立核验实物和必要返修，记录提交或指纹、真实命令及结果。区分阶段和整批；千页向量基准与真实 25 问三引擎评分由 1B-3 完成。 |
