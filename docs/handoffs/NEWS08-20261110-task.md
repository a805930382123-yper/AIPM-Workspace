# NEWS08 今日新增＋近期精选冻结卡

2026-11-10，用户授权本轮产品实现。复用 NEWS07 已通过的采集、去重、时间与缓存规则。评分需求0/耦合2/风险1/历史0=3，A标准：Astra Medium规划，Sol High预审，Terra High施工，不同实例Sol High独验；实际调用由主线程记录。仅本卡为规划者写入范围。

## 目标与接口

快消今日视图分“今日新增”和“近期精选”，今日成功条目优先，两组合计最多5条。“新增”指本期首次收录，不等于今天发布；继续展示实际发布日期。近期精选只复用已有正文，补足剩余展示名额，不保证5条。

1. `NewsService.today()` 增加只读投影 `recentFmcg`（推荐 `{date:string,item:NewsItem}[]`）；不写入 NewsEdition、不迁移或重建今日缓存、不改变 ensure/retry/run 抓取逻辑。API仅传递新增投影；旧消费者忽略新增字段仍可工作。客户端缺字段视为空。
2. 取上海今日D之前30个自然日 `[D-30,D)` 的成功 `ready/source_only`、`contentVersion=research-v1` 快消记录；普通旧新闻、legacyFmcg、失败/空/中断/运行中记录均不入选。报告发布日期须有效，仍处现行365日范围（D上海零点减364日到当前时刻），未知/未来/过期不选。
3. 今日新增来自当前成功新版快消 section.items，沿用原序且最多5；不修改其缓存。历史精选对今日新增及自身按 normalize.ts 的URL/标题去重。先按原收录期刊日期倒序，日期相同沿用期刊条目顺序；该顺序已经包含当期中国优先，不重新做模型排名。重复历史保留最近合格原期刊副本，其“原收录日期”明确表示该条原期刊日期，不宣称全库最早收录日期。
4. 近期精选数量为 `5 - 今日新增数量`，允许来自多个期刊；每条保留原日期、原 fetchedAt、原正文及链接，不能伪造今日抓取。投影必须带原 date，Raw保存/状态查询继续调用该date对应既有接口。为查询不同原期刊保存状态增加本地API读取属于范围内；不增加外部来源请求。

## 状态与页面冻结

- 今日成功且有新增：显示“今日新增 N 条”“近期精选 M 条”，总计N+M/5；新增解释“本期首次收录，并非今日发布”。原不足原因属于“今日新增不足原因”，不能因为历史补足改称本次采集5条。
- 今日empty：显示“今日暂无新增”，近期精选照常；今日失败/中断：保留原错误、重试与今日尝试时间，显示“今日读取失败/中断”，近期精选照常，不能写今日成功或暂无新增。running：显示“今日正在准备，新增数量待定”，暂展示最多5条近期精选，完成后重新计算剩余名额。无记录/等待升级：显示“今日尚未准备”，可展示历史精选，不自行触发额外抓取。
- 今日快消不再额外渲染旧 `fallbacks.fmcg` 整栏（避免和近期精选重复、超5或越过30日范围）；后端可保留该兼容字段。AI fallback、AI源顺序/5条/分析行为保持。没有近期合格条目就显示无近期精选，不扩大时间窗。
- 每条近期精选明确“原收录：YYYY-MM-DD”“原抓取：上海时间”，无效时间显示未记录；今日尝试时间只属于今日状态。历史日期选择保持原期刊内容，不拼接当下近期精选，不标“今日新增”，可用“本期收录”；普通旧快消与legacy区原样保留。
- Raw保存必须携带原期刊date与item.id，保存后已保存/缺失/待核对以及错误提示正确归属；跨期多个保存状态查询日期去重。不得把历史条目复制进今日缓存或改写正文来保存。近期精选刷新后仍能显示已有保存状态。

## 验收标准

- N8-01：2条今日＋跨两天历史补3、0＋5、5＋0；URL跟踪参数/规范标题重复排除，两组合计≤5，今日原序不变。固定覆盖D-30包含、D-31排除、365日边界、未来/无日期排除、旧版/失败历史排除、跨历史重复与确定顺序。
- N8-02：today重复读取、同日ensure复用已有缓存无新增外部请求；今日及历史JSON字节不变。投影只存在响应，不落盘；缺可选字段旧客户端数据可显示。历史损坏沿现有错误提示处理，不把不可读记录当合格来源。
- N8-03：empty/failed/interrupted/running/无记录/成功分别检验文案与分组，失败不伪装暂无新增；AI原行为回归。选历史日期不混入今天精选；快消不重复显示fallback；补足仍保留今日不足原因语义。
- N8-04：通过真实隔离服务保存近期条目，URL使用原date；原文逐字、幂等、刷新保存状态、原Raw删除后missing行为正确；今日缓存不增加历史条目。固定覆盖跨期在途回归：原期刊A保存成功时，仍在请求中的原期刊B保存状态响应不得被全局版本失效后永久丢弃；B最终正确显示已有保存状态，且A不能被旧响应覆盖。
- N8-05：真实浏览器桌面及手机查看分组、跨期日期/时间与保存行为，允许隔离fixture但披露；JSDOM覆盖状态矩阵不能冒称真实浏览器。产品范围类型检查、隔离空env构建及news01/02/03/07受影响回归通过；全仓旧受损测试不顺带修复。
