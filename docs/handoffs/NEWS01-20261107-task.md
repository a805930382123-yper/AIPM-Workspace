# NEWS01 每日资讯首批任务卡

日期：2026-11-07。规划读取基线：`1f9ca7798df269bab84868a18d3ef8b28e3e94a2`；共享工作区后续并行提交不自动归本任务。

## 授权、范围与交付边界

用户批准第一批：先验证公共来源，再跑通取得内容、生成、保存、展示；本轮不调用付费产品模型。每日阅读分「快消行业」与「AI 前沿」，快消目标 3 条、最多 5 条，AI 最多 3 条；不足不编造补齐。生成版每条有事实、为何值得关注、可能影响、来源日期和链接，目标阅读 5–8 分钟。事实与 AI 分析分别存储和标示。

A 模式：打开工作台触发当天首次准备；当天已有记录复用，不部署定时器、不在无人打开时抓取。两栏独立运行与失败；失败显示上一期内容及其真实日期，并允许只重试失败栏。支持历史只读。日期一律 Asia/Shanghai。

本轮真实可用形态是**无 AI 来源阅读模式**：取得真实公开来源摘录，保存并可读；明确显示“AI 分析未启用”，为何值得关注/可能影响标为“未生成分析”，不得以固定模板推断充当模型结论。生成链用隔离 fake 验工程；真实模型分析质量及 5–8 分钟分析版阅读质量为 NOT_RUN，不因此宣称完整 AI 日报通过。若真实来源覆盖门禁未满足，批次整体不得 PASS，即使工程链通过。

不做课程、收藏、Raw 沉淀、消息推送、数据库、RSSHub/TrendRadar 部署、产品 Agent 或付费模型质量试跑。输入仅公开新闻，不读取正式 Raw/Wiki、用户问题或秘密。开发 Agent 不进入产品运行时。

## 评分、角色与施工门禁

评分 0/2/1/0=3，A 标准：目标明确；跨获取/服务/HTTP/UI；新增可逆新闻草稿且不改正式资产；无本批有效失败历史。规划 Astra，Terra High 单一施工者，Sol High 先审计划并独立验收；最终报告记录实际实例与模型，不能仅引用此声明。施工前须 Sol 计划通过并由主 Agent 发施工指令。

来源门禁：施工者先记录本机实际产品 Node 的请求命令、时间、状态/异常、解析条目样本、原始日期与链接、品牌食品/渠道/AI 覆盖；文档可读不等于运行时可达。候选 Foodaily 公开列表/详情、CCFA 公开渠道栏目、AIHOT `/api/v1/items`。允许经过同样验证的替代公共来源，不改变覆盖目标；不得将一个食品资讯源冒充渠道覆盖。

当前调查仅供定位：施工者回报沙箱内域名 ENOTFOUND；提权只读直连 AIHOT 200 JSON（15 条，含标题/summary/source/原文链接/publishedAt）；Foodaily/CCFA HTTPS ECONNRESET。替代食品源 `http://www.ce.cn/cysc/sp/` 列表及 11/06 可口可乐详情本机均 200；商务部首页可读，零售栏目/详情仍待核验。AIHOT 此次类别不覆盖快消，不能替代。此处不是来源验收结论。若某类仍无可用来源，向主 Agent 交明确阻塞，不静默删去该类标准。

本机 DNS 存在 198.18/15 透明网络地址，既有通用 `readPublicRawUrl` 会拒绝；不得为本批修改其安全约束。新闻采用固定站点适配器，可使用 Node fetch，限制为已核验来源域名及其实际跳转范围；不提供任意 URL 输入。可保留已核验站点真实 HTTP 链接，不凭空升级 HTTPS 导致不可达。

主 Agent 已批准最终替代组合：中国经济网食品 + 商务部首页公开零售动态 + AIHOT 摘要；实际来源报告见 [来源证据](../reports/NEWS01-20261107-sources.md)。商务部首页发现与详情可读，独立栏目列表依赖脚本、不能声称已解析；已取样零售报道日期为 2026-10-26，不得标今日。来源连通/覆盖通过不代表每日均有近期足额新闻；超过近期窗口则本期不足，并明确渠道近期内容缺口。

## 最小实现与所有权

单一施工者拥有 `services/news/{types,sources,service}.ts`、`server/news-api.ts`、`server/index.ts` 新闻装配、`app/pages/NewsPage.tsx`、`app/news.css`、`app/App.tsx`、`app/pages/HomePage.tsx`、`app/api.ts` 新闻增量、新闻专用测试及施工报告。本卡归规划者，状态/总控/统一提交归主 Agent，独验报告归独验者。多人共享工作区，先检查现有差异，不回退他人修改；同文件并行编辑先协调。

存储冻结在 `state/news`，避开现有 stats 对 drafts 的递归读取；不授予 stats 修改所有权，不改其它统计口径。

复用 `writeJsonAtomic`、`SerialQueue`、既有 HTTP 本机写入门禁与 Provider，不引依赖、不改通用 Provider 业务能力。新闻服务构造参数明确注入 `root`、时钟、来源读取函数、`aiEnabled`、异步 `providerFactory`；测试直接注入 fake，正式路由不能选择 fake。默认装配只在 `process.env.FMCG_NEWS_AI_ENABLED === 'true'` 时允许加载/调用工厂；本轮不得为用户服务设置此值。不得从现有 Key 是否存在推定启用。调用时捕获 Provider 快照，不能依赖 HTTP 退出后的 AsyncLocalStorage `activeProvider`。

## 数据与运行契约

持久化 `state/news/YYYY-MM-DD.json`，`schemaVersion:1`、`date`、`updatedAt`、`sections:{fmcg,ai}`。每栏最小字段：`status`（running/ready/source_only/empty/failed/interrupted）、`attempt` 单调整数、`startedAt`、可选 `finishedAt/error`、`sources` 健康记录、`items`。不存在当天文件/栏即未尝试，无需额外 idle 写盘。

条目：稳定 `id`、`title`、`sourceId`、`sourceName`、`url`、`publishedAt`（无法核实为 null，UI 明示日期未知）、`fetchedAt`、`excerpt`、`evidenceKind:'article_excerpt'|'source_summary'`、可选 `analysis:{fact,whyItMatters,possibleImpact}`。excerpt 为原来源短摘录，不冒充全文或 AI 整理；AIHOT 若只取其摘要则标记 source_summary 并显示“AIHOT 来源摘要，未核验原文”，保留 original link 不声称已读该文章。提示词明确材料等级，不能依据未取得的正文生成事实。分析必须对应本栏给定 source item ID，服务端回填来源字段，不接受模型发明链接/日期。可能影响标为推断，不与原来源事实混存。source health：源名、checkedAt、ok/empty/failed、错误摘要；200 但解析格式异常是 failed，合法无条目才是 empty。有可用来源且部分失败时可展示内容并明确覆盖不完整；全失败是 failed。

选条优先最近可核验日期，去重规范化链接；最多抓取/保存每源 20 个候选、每个摘录最多 1500 字符，详情只用于必要提取，不保存整站/全文。采用已批准近期窗口：快消最近 72 小时、优先 24 小时；AI 最近 24 小时；过去 7 日只用于已展示条目去重。无法核实日期的候选仅保留诊断，不选为新近新闻；实际 source 日期不被 edition date 替换。快消目标 3 条、上限 5，AI 上限 3；不足如实提示。模型输入限定为本次有界候选，输出严格结构校验及每字段长度限制，不允许超额条目或未知引用。来源 HTTP 有超时、体积上限和最大详情数，固定服务端来源地址，不开放用户任意抓取代理。

24/72 小时按本次尝试开始时刻计算滚动窗口，发布时间晚于该时刻的候选不入选；只有日期无时分时按来源明确时区日界（中国来源按上海）归一化并保留原日期精度，不虚构具体发布时间。七日去重按同栏目规范化链接，对照最近七个上海日期内已保存、实际展示的条目；同次候选也去重。fallback 查找最近可读旧期不受七日去重窗口限制。

每次先串行持久化该栏 running 与 attempt，再开始外部操作。日期文件的短读改写全部串行，网络不占该锁；两栏提交合并当前文件，不能用旧整份快照覆盖另一栏。进程内同日同栏运行去重；auto ensure 对已尝试状态一律复用，失败/中断只由手动 retry 重启。无活动任务的磁盘 running 在读取投影为 interrupted，不自动重新外发。每次尝试最多一个模型请求/栏，无隐式网络或模型重试；自动每天每栏最多一次。成功/source_only/empty 不提供重新生成按钮。禁用 AI 时任何入口均不得调用 providerFactory/complete。

历史按 date 降序读取，错误文件不可当无记录或空成功，不覆写损坏原件。单日序列化 JSON 必须低于既有 2 MiB 单记录预算，拒绝超限写入并保留旧内容。只保留当前尝试状态与计数，不无限累计响应/错误历史。已有 `scripts/backup_workspace.ts` ROOTS 包含 state，需实际往返证明新嵌套目录被覆盖，不增备份格式。新闻不在 drafts 下，因此不进入 DraftStore 与 stats 的草稿枚举；验收核对该行为保持。

## HTTP 与 UI 冻结接口

统一 `/api/news`：

| 方法 | 路径 | 契约 |
|---|---|---|
| GET | `/today` | 只读；返回 `date,aiEnabled,edition|null,fallbacks:{fmcg,ai}`；fallback 为最近该栏可读内容与其真实 date，禁止当今日完成 |
| POST | `/today/ensure` | 无业务正文；首次启动缺失栏，其余复用；立即返回同一视图，后台任务不阻塞 HTTP |
| POST | `/today/retry` | `{section:'fmcg'|'ai',attempt:number}`；仅 failed/interrupted 且版本匹配可运行；重复并发不多发，过时 attempt 返回 409；不影响另一栏 |
| GET | `/history` | 返回日期/两栏状态摘要、读取错误提示；不抓取、不生成 |
| GET | `/editions/:date` | 校验真实 YYYY-MM-DD，返回对应 edition；缺失 404，损坏明确错误；不抓取、不生成 |

today 的 fallback 仅取 `date < today` 最近该栏 ready/source_only 且 items 非空的记录；今日 failed/interrupted 与旧期状态、日期并显，旧期不写入今日。今日有可读成功内容的栏不回退。关闭 AI 仅阻止新调用，历史已有分析仍可读且标记原生成日期，不降格或删除已有分析。

NEWS POST 明确采用 JSON（ensure 发送 `{}`）；依现有应用规则检查 loopback Host、同源/允许的本地 Vite Origin，拒绝 cross-site 与 `Origin:null`。现有门禁并无共享 helper，可在新闻路由局部实现，不能使用配置专属写令牌或读取 `.env` 来校验来源。门禁失败在写盘、抓取、Provider 工厂之前返回，测试直接覆盖。

首页挂载调用 ensure，返回/轮询 today；仅存在 running 时有限间隔轮询，离页取消，首页可见两栏状态和阅读入口。新闻页两栏目、日期、来源链接、出处事实/分析区、独立失败提示和重试；历史阅读不得触发 ensure。状态变化及慢响应不能覆盖用户后来选择的历史日期；卸载不写过时 state。全局保持原首页跟进与其它模块入口可用。沿已批准 `DESIGN.md` 紫白风格，新闻正文采用 Read 单列，1440px 与 390px 可读；外链仅允许经来源适配器核验的 HTTP(S) URL 并设置 rel，HTTP 来源明确标示 HTTP，来源文本按纯文本或现有安全 Markdown 渲染，不加载来源脚本/图片。

## 验收 ID 与必备证据

| ID | 场景与通过依据 |
|---|---|
| N01 来源 | 本机实际 Node 对品牌食品、渠道、AI 三类均有可解析真实内容与日期/链接证据（来源能力证明可用历史样例，当前期超过窗口不选；渠道当期0条允许但明确缺口）；失败和合法空区别；部分源失败明确覆盖缺口；不同类别不虚构合并。来源证据不足即来源门禁未过 |
| N02 无付费边界 | 完整既有模型配置存在但 news 开关缺失/false：打开首页、ensure、retry、历史、重启全部 providerFactory/complete 计数 0；真实 UI 无 fake；真实来源可读落盘，清晰未生成分析 |
| N03 生成工程 | 隔离 fake 单栏一调用，结构合规分析保存读回；空/超限/错误 JSON/未知 source ID/超时失败明确，另一栏成功保留；失败不落假 ready；真实质量 NOT_RUN 单列 |
| N04 同日与中断 | 并发 ensure 每栏只一次；双栏交错完成不丢数据；同时 retry 仅一次；重载复用；预写 running 后重启不重发、仅手动指定栏重试；上海跨日与服务器本地时区不同仍正确 |
| N05 展示与历史 | 真实浏览器宽窄视口：首次状态、无AI内容、来源打开、失败栏旧日期回退、只重试该栏、成功栏不受影响、无历史时真实提示、历史读取与迟到响应隔离；历史页不触发生成 |
| N06 持久化与回归 | 正常备份恢复包含新闻；旧无新闻备份仍兼容；日期路径/损坏/超2MiB记录明确拒绝且原件保留；实际 getStats、knowledge drafts、home actions 在已有及损坏 news 记录后保持可用，新闻不计为待确认提取草稿；NEWS POST 来源门禁拒绝时写盘/外部调用计数为 0；必要类型检查/空 envDir 构建和既有首页相关回归通过 |
