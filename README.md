# 快消 AI 产品经理工作台

截至 2026-11-09。本项目是一个在本机运行的快消品 AI 产品经理工作台：把行业资料、知识整理、客户事项、产品分析和 Prompt 模板放在一处，按需要调用你自己配置的 OpenAI-compatible 模型服务。

工作流示例：**研报 → Raw 原始资料 → Wiki 知识 → 按需关联到事项；选用 Wiki 背景生成 Prompt**。Raw 保存来源原文，AI 结果先进入草稿，用户检查并明确操作后才写入正式知识或模板。产品独立运行，不依赖 Codex、Agent CLI 或 Obsidian。

## 功能概览

- 首页查看每日资讯、知识与事项概览，打开只读周期回顾，并从快捷入口继续处理。
- Raw 保存文件或粘贴资料及来源信息；保留原文，可关联到 Wiki 和事项。
- 知识 Wiki 按主题组织页面，支持搜索、来源回跳、Audit、Lint 与显式审核写入。
- 客户工作事项记录沟通、技术回复、复测及关闭/重开；产品事项支持多轮 AI 分析和阶段成果。
- Prompt Library 管理模板；Generator 将自然语言任务整理为 Prompt Brief 并生成模板草稿，Optimizer 提供优化草稿。
- 会议档案按独立授权规则管理纪要与来源。
- 本地数据可离线备份和恢复。

## 安装与启动

### 环境要求

- Windows 是主要验证环境。
- Node.js **22.13 或更高版本**；Windows 代理启动脚本需要 Node.js **22.21+ 或 24.5+**。
- 前端默认端口 `5173`，本地 API 默认端口 `4317`，服务仅监听本机回环地址。

### 从源码运行

```powershell
git clone https://github.com/a805930382123-yper/AIPM-Workspace.git
cd AIPM-Workspace
npm install
npm run dev
```

在浏览器打开 <http://127.0.0.1:5173/>。停止服务请在终端按 `Ctrl+C`。

也可以在 GitHub 仓库页面选择 **Code → Download ZIP**，解压后在项目目录运行 `npm install` 和 `npm run dev`。

若本机访问模型服务需要已有的 Windows HTTP 代理，可运行 `npm run dev:proxy`。脚本使用当前进程代理环境变量，或读取已启用的 Windows 手动代理；不读取 PAC，也不修改系统设置。

### Windows 后台常驻

在项目目录运行 `npm run build` 后，用 `npm run start` 启动生产模式。在浏览器打开 <http://127.0.0.1:4317/>，页面与 API 使用同一端口。生产与开发进程共用数据目录时须先停止已有进程。直接运行的进程可用 `Ctrl+C` 停止。

如需当前 Windows 用户登录后自动启动，在 PowerShell 运行以下命令。安装脚本会列出配置并等待确认，`-Yes` 可跳过确认。任务通过 Windows PowerShell 5.1 隐藏运行，登录时触发，也可以手动启动。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\service\install-autostart.ps1
Start-ScheduledTask -TaskName 'AIPM Workspace'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\service\status-autostart.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\service\uninstall-autostart.ps1
```

安装可选 `-TaskName`、`-Port`、`-DataDir`、`-NodePath`、`-ConfigFile` 和 `-UseProxy`。状态与卸载命令使用同一个 `-TaskName`。代理沿用开发代理启动脚本。每次任务启动后，启动器遇到失败会等待 1 分钟再试，最多重试 3 次。工作台正常退出时本次任务结束。后台启动、退出和重试记录按天放在数据目录的 `state/runtime-logs/`，保留最近 14 天。卸载会停止启动器及其工作台进程并移除计划任务，工作区数据保留。

在侧栏打开「自动化」可编辑间隔、每日或每周计划，也可立即运行、查看记录或全局暂停。每日和每周计划使用上海时间。内置的系统自检每 60 分钟运行一次，检查本机运行条件，模型请求次数为 0。只有工作台进程运行时才会执行计划。启动时，启用补跑的任务最多补跑最近一次。

### 知识库定时巡检

知识库结构巡检默认每天 08:00 运行，保存检查结果及较上一次新增、消除的问题，模型请求次数为 0。主动巡检默认每周一 08:30 运行，最多将 8 篇符合来源权限的主题页发送给配置的模型。模型请求或费用可在运行历史和服务商账单中查看。两项任务均可在「自动化」单独暂停。

从「自动化」查看最近的巡检摘要及运行明细。首页只在有新增结构问题或主动检查待核发现时显示入口。巡检只保存结果。审阅发现、生成维护草稿和确认写入正式 Wiki 仍由用户在知识库中操作。

### 工作事项提醒

工作台默认每 60 分钟扫描一次到期跟进、久未推进事项和产品事项待分析的新资料。打开侧栏「自动化」里的「事项提醒」可标为已读、延后一天或打开对应事项。产品事项的「前往分析」会定位到本轮资料，资料仍由用户选择并确认分析。扫描本身使用 0 次模型请求。

在「提醒与通知设置」可关闭桌面通知，修改上海时间的免打扰时段、久未推进天数和单次通知上限。默认每天 22:00 至次日 08:00 只更新站内提醒，久未推进阈值为 7 天，单次最多 3 条系统通知。设 0 天可关闭久未推进提示，免打扰起止时间相同可取消该时段。Windows 桌面通知仅显示事项标题、提醒类型和简短数量。「发送测试通知」使用固定文案检查系统是否受理。

### 自动资讯流水线

工作台运行期间，默认每天上海时间 07:30 准备快消研报和 AI 前沿资讯。可在「自动化」调整计划或点「立即运行」。当天已准备的资讯复用缓存。首页「今日资讯流水线」或「自动化」内的收件箱可查看当天及往期候选。低相关性条目默认折叠，未预筛条目照常显示。可忽略、恢复或稍后处理。

在收件箱选择一条或多条资讯，确认对话框会列出将保存的来源摘录或来源摘要。「确认后自动整理」默认勾选，默认模式为标准，可改为深度或取消勾选。确认后系统排队保存 Raw，勾选时发起一次 AI 整理。整理完成的草稿进入首页待审，正式写入 Wiki 仍须打开草稿并人工确认。保存或整理失败可单独重试，已中断的整理需要手动继续。

「流水线设置」可修改关注主题、关闭 AI 预筛及调整整理并发数。「暂停全部自动化」会停止发起新任务，已确认队列保留。预筛将候选摘录与关注主题发给配置的 Provider，整理将对应 Raw 发给同一 Provider，服务商可能收费。运行历史分别记录来源 HTTP 请求、模型请求、Token 及未知用量。本流水线不设费用上限。

### 设置模型

打开「设置」，填写服务商提供的 API Base URL、模型 ID 和 API Key，保存后再按需点击「测试连接」。产品通过你配置的 OpenAI-compatible Chat Completions 服务发送请求。设置页不会自动调用模型；连接测试会发送固定的非业务消息，服务商可能收费。

API Key 由本机服务端读取，不进入普通业务数据或备份。环境变量和项目根目录 `.env.local` 可用于本机配置；不要把密钥提交到代码仓库。模型请求会把你在界面确认发送的资料交给对应外部模型服务，请先查看预览及来源限制。

## 各板块怎么用

### 首页与每日资讯

首页展示工作台概览和可继续处理的事项，并提供导入资料、审核草稿、生成 Prompt、新建会议等入口；新建客户或产品事项请从侧栏「工作事项」进入。首页资讯按来源呈现，不代表完整市场覆盖；内容不足时不应据此推断没有相关新闻。

在首页打开「每日资讯」中的「阅读资讯」。「快消研报与洞察」选取 Worldpanel 中文研究与 NIQ 官方近 365 天的研报，中国市场优先，最多 5 篇。「AI 前沿」读取 AIHOT 的 24 小时精选，按来源顺序取最多 5 条。内容按上海日期缓存，可查看历史；点「保存来源摘录到 Raw」只保存已取得的摘录或来源摘要，后续整理需在 Raw 中另行发起。设置 `FMCG_NEWS_AI_ENABLED=true` 且已配置模型时，准备当日资讯可为 AI 前沿生成分析。

### Raw 原始资料

将研报、网页摘录或其他文件导入 Raw，并记录标题、来源、日期等信息。支持粘贴、上传文本/Markdown、DOCX、PDF，上传上限 20 MiB；文本型 PDF 可提取文字，扫描件、加密或损坏 PDF 可能无法解析，当前没有 OCR。仅以链接导入时，默认勾选英文内容的中文翻译，可取消。原文先保存，译文独立展示；引用仍定位原文。

Raw 用于保存输入资料和追溯出处；正文不由 AI 改写。知识页和事项可以关联 Raw，之后可从引用回到原资料。打开 Raw 后选「标准整理」或「深度整理」，再点「整理到知识库」。整理需阅读材料并按主题说明来源、关键事实、证据、反例和待确认点；审核所选主题和证据后明确确认写入，不要把标题或短摘要当作完成的知识页。

资料整理和分析前先确认实际发送范围。原文可能包含未经核实的主张；AI 生成的摘要、标签和建议需要自行检查。知识整理应达到足以让另一位读者理解主题、来源、关键事实和不确定性的深度，不要只保存标题或一句泛化摘要。

### 知识 Wiki

按主题创建或维护 Wiki 页面。可以通过搜索找到知识、查看关联来源，并使用 Audit 提交具体段落或整页的审核意见；Lint 用于发现链接、来源和结构问题。打开「向知识库提问」，从回答引用跳回来源。选中需要回存的回答片段并编辑预览，点「生成维护草稿」；可建议新建主题或更新已有主题，审核确认后才写入正式 Wiki。也可对相关主题做更新或多来源综合，检查引用、差异及待确认事项后审核。

AI 整理、更新或综合内容先显示为草稿/预览。阅读中文内容和来源证据，确认事实、推断、反例及待核问题，再明确保存或接受。Raw 正文保持原样，不把 AI 草稿当作已核实事实。编辑草稿后须重新审核。

### 客户工作事项

建立事项后记录客户/项目、发生时间、等待对象和下一步。手工记录已发送内容、回复客户（仅本地记录，不会外发）、技术回复与复测结果。要结束事项，使用「标记为已解决」，填写必需的解决说明并确认保存；需要继续跟进时可重开。事项中的回复和状态修改保存在本机工作区。

设置跟进日期后，到期且未解决的事项会出现在首页。客户或产品事项删除会移除事项记录，但保留关联 Raw 原文；删除前查看确认提示。关闭、重开和删除均由用户操作；工作台不会代替用户联系客户。

### 产品工作事项

在产品事项中补充目标、口径、已确认结论、未解问题，并选择本轮要分析的 Raw。可以显式选择一条已保存阶段成果继续分析，查看发送范围后发起本轮。后续轮次展示本轮摘要、主题结论或假设、支持证据、反例、未决问题和下一步；证据不足时应保留待验证状态。

分析结果是草稿。可编辑后保存为阶段成果，或在单独的「当前情况」区域确认结论。需要时对某轮分析显式发起依据复核；复核与确认是不同操作。规则建议只有在用户点击应用后才更新事项状态或下一步。

自动接收外部事件、后台提醒和 WORK05 外部来源试点尚未实现。不要把页面中手工录入或演练数据理解为已接入外部平台。

### 会议档案

会议档案可用「云端索引」记录会议信息、目录/标签、搜索和手动登记的来源链接，不保存正文。需要保存纪要时，按策略选择本地归档；Internal/Sensitive 需另行确认获得本地保存授权。仅符合策略的 Public/Internal 纪要可再单独授权并明确登记为 Raw。**新会议来源始终禁止用于 AI、Wiki 或 Prompt 背景**；档案解除或删除也不会解除已登记 Raw 的限制。录入前阅读界面显示的授权提示。

### Prompt Library、Generator 与 Optimizer

Library 是手动维护的模板库，可以搜索、分类、收藏、编辑、查看版本并导出 Markdown。模板变量使用 `{{变量名}}`；在 Library 中填写变量并预览最终正文，再复制。

Generator 从自然语言任务描述开始，生成结构化 Prompt Brief。检查并修改 Brief 后，可选择 Wiki 背景生成 Prompt 草稿，预览并明确保存为新模板。演示数据入口位于设置中，可帮助熟悉界面；内容有演示标识，不是实际业务资料。

Optimizer 根据用户提供的目标生成优化版本草稿。检查差异和内容后，再明确保存为新 Prompt 或已有模板的新版本。生成、优化和变量预览本身不会自动改写正式 Library；使用反馈也由用户提交。

## 数据备份与恢复

备份前先停止工作台服务。备份只读出产品工作区数据，不包含 `.env.local`、模型密钥或配置文件。恢复请使用一个新的空目录；不要把正式数据目录作为恢复目标。

```powershell
# 导出到备份文件
node --import tsx scripts/backup_workspace.ts export --data-root .\workspace --output .\workspace-backup.json

# 恢复到新的空目录
node --import tsx scripts/backup_workspace.ts restore --input .\workspace-backup.json --data-root D:\AIPM-Restored
```

备份覆盖 `knowledge`、`prompts`、`drafts`、`state`、`meetings`、`work-items` 六个数据目录（Raw 位于 knowledge，反馈位于 prompts）。单文件最多 64 MiB、原始文件合计最多 256 MiB、最多 20,000 个文件；恢复时会验证文件长度和 SHA-256。默认数据目录是项目下的 `workspace/`；恢复后可设置 `FMCG_DATA_DIR` 指向恢复目录再启动：

```powershell
$env:FMCG_DATA_DIR = 'D:\AIPM-Restored'
npm run dev
```

备份文件也可能包含个人或业务资料，请按敏感文件管理并放在安全位置。

## 当前限制

- 这是本机工作台，不提供托管服务、多人协作或云端数据同步。
- AI 输出可能错误或遗漏；结构校验不能证明观点正确。正式保存前需要核对来源和上下文。
- 会议新来源不能进入 AI、Wiki 或 Prompt；支持的来源和授权行为以页面提示为准。
- 产品事项的后台自动提醒与外部事件自动接收尚未实现；模型分析质量仍需结合实际事项评估。
- 项目历史批次和局部验收结论不代表整个产品已完成统一验收，也不保证所有模型、平台或 Node 版本均已实测。

## 常见问题

**页面打不开或端口被占用怎么办？** 先确认 `npm run dev` 仍在运行。前端默认使用 5173、API 默认使用 4317；检查本机端口占用后再启动。可通过 `FMCG_PORT` 修改 API 端口，前端代理会使用同一配置。

**必须配置模型才能使用吗？** 不需要。Raw、手动 Wiki、客户事项和 Prompt Library 等手工功能可本地使用；需要 AI 的操作才依赖已配置 Provider。

**模型连接失败怎么办？** 检查服务商的 Base URL、模型 ID、Key 和网络访问。若使用 Windows 代理，可按上文使用 `npm run dev:proxy`；设置页的连接测试会显示错误，不会自动重试。

**怎么更改数据目录？** 启动前在 PowerShell 设置 `$env:FMCG_DATA_DIR`，然后运行 `npm run dev`。默认目录为项目根目录的 `workspace/`。

**文件导入失败怎么办？** 确认格式受支持且不超过 20 MiB。扫描版、加密或损坏的 PDF 可能没有可提取文本；当前不提供 OCR。保留原文件，尝试文本型 PDF 或可读取的 DOCX/文本文件。

**AI 结果会直接写入 Wiki 或 Prompt 吗？** 不会。AI 输出先进入草稿或预览，用户检查并明确保存后才改变正式内容。

**备份会保存 API Key 吗？** 不会。备份包含工作区业务数据，不包含本机模型配置或密钥。

**在哪里查看技术细节和历史验收？** 见下方详细文档。旧版 README 保留较完整的技术与接口记录，可查看 [固定版本 README（956910b）](https://github.com/a805930382123-yper/AIPM-Workspace/blob/956910b90e0f238e8c024dc9f8ffdddaeb0fa765/README.md)。
