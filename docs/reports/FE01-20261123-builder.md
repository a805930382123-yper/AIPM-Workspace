## 1. 交付摘要

1. **`app/api.ts` 按域拆分与桶导出保兼容（FE01-01）**：
   - 将原 `app/api.ts`（`55,053 B` / `1,413 L`）拆分为 8 份无环域子模块：叶模块 `app/api/client.ts`、`app/api/meeting.ts`、`app/api/wiki.ts`，以及域模块 `app/api/raw.ts`、`app/api/automation.ts`、`app/api/work-items.ts`、`app/api/llm.ts`、`app/api/prompt.ts`；未创建 `app/api/index.ts`。
   - 重写 `app/api.ts`（`318 B` / `9 L`）为纯桶导出文件，显式导出 `{ ApiError, api, apiForm, bytesText, dateText, type RecoveryScan, type Stats }`，其余 7 个域通过 `export * from './api/<domain>'` 重导出；内部 `readResponse` 仅保留在 `app/api/client.ts` 私有作用域，并通过内部 helper `apiText` 支持 `automation.ts` 的 `weeklyReviewMarkdown`，`app/api.ts` 公开运行时导出键精确等于 **130** 项基线（无 `readResponse` / `apiText` 泄露）。
   - `RawStatus`、`rawStatusLabels`、`jobStageLabels` 与 `MediaEvidenceSource` 随 `DraftEvidence` 统一归入 `app/api/llm.ts`，`app/api/raw.ts` 与 `app/api/llm.ts` 保持单向依赖；所有相对 `services/` 路径均改为 `../../services/...` 且全量为纯 `type` 导入/导出（含原内联 `InspectionFinding` 与 `FeedbackDto`/`FeedbackInput`）。
2. **轻量路由与异步 Hook（FE01-02 / FE01-03）**：
   - 新增 [`app/router/routes.ts`](../../app/router/routes.ts) 与 [`app/router/useAppRoute.ts`](../../app/router/useAppRoute.ts)：声明 `APP_ROUTES` 与 `MEETING_QUERY_KEYS`，实现 `isAppPage`、`getPageTitle`、`getForeignQueryKeys`、`stripForeignQueryParams`、`buildUrlWithParams`、`parseLocation`、`readLocationSearch`、`readQueryParams`、`updateRouteQuery`、`subscribePopState`、`useAppRoute()`。全部浏览器 API 经 `typeof window !== 'undefined'` 访问；按 `targetPage` 清理异页 query keys；切出 `meeting` 时精确清理 8 个会议参数并保留无关参数与 `#hash`；导航不向 URL 写入 `?page=`；`updateRouteQuery` 保留 `window.location.hash` 与现有 `window.history.state`；`navigate` 仅在 `changed` 为真时调用 `replaceState`（保持 `tests/app-navigation.test.tsx` 等多挂载测试兼容）。
   - 新增 [`app/hooks/useLatestAsync.ts`](../../app/hooks/useLatestAsync.ts) 与 [`app/hooks/useScopedQuery.ts`](../../app/hooks/useScopedQuery.ts)：支持 React StrictMode、禁止在 render 期调用 `setState`；`useLatestAsync` 通过递增请求序号与 `AbortController` 自动作废旧请求并忽略 `AbortError`；`useScopedQuery` 默认 `cache: false`，采用确定性段编码 `serializeScopeKey` 与前缀匹配 `invalidateScopedQueries(prefix?)`（支持元组与字符串前缀）及 `clearScopedQueryCache()`，通过快照标签派生状态消除 A→B→A 竞态覆盖与 `set-state-in-effect`。
3. **6 份目标前端文件 React Hook 与静态告警治理（FE01-04）**：
   - `app/App.tsx`：接入 `useAppRoute()` 与 `useLatestAsync`；`rawSelectionGeneration` 采用同步 ref + state 双轨同步；JSX 仅读取 state；首屏 `initialLoading` 完成后永久置 `false`；`refresh()` 内部捕获错误写入 `loadError` 并始终 resolve `Promise<void>`。
   - `app/pages/MeetingPage.tsx`：接入 `routes.ts`（`readQueryParams`/`updateRouteQuery`）与 `subscribePopState`；新增 state 版 `modalToken` 配 `modalTokenRef`；删除多余三元表达式语句；拆出 `fetchDirectoryAndDetail` 消除挂载 `set-state-in-effect` 且不将 `selectedId` 放入挂载 `useEffect` 依赖。
   - `app/components/WikiQuestionPanel.tsx`：将 `askedId` 改为 React state，并将初始 `useEffect` 改为局部取消标志 `active`。
   - `app/MeetingRawLinks.tsx`：拆出 `<MeetingRawLinksContent key={props.meeting.meeting_id} {...props} />` 外壳自动复位局部状态，将 `meetingIdRef` 同步移入 `useEffect`，以 `revisionOverride`（关联 `meeting.revision`）与 `selectedImportId` 派生 `revision`/`importId`。
   - `app/pages/DraftReviewPage.tsx`：顶层提升 `duplicateInput`；拆出 `key={props.draftId}` 外壳；接入 `useScopedQuery` 读取 `/api/wiki/schema`（`cache: false`）；`canCheckDuplicates` 提取防抖检查依赖 `[draftId, canCheckDuplicates, view?.revision, pages]`（不直接依赖 `view` 对象）；补充 `mountedRef` 保护 `makeUpdate`、`discard` 与 `run`；消除未使用变量告警。
   - `app/pages/PromptLibraryPage.tsx`：提升 `startCreate` 至监听 effect 前并使用 `useCallback`；将 `selectedIdRef`/`formActiveRef`/`conditionsRef` 同步移入在列表请求 effect 前声明的 `useEffect`；保留 `onLibrary` 同步更新 `conditionsRef.current`；移除 `!selectedId` 时 effect 内同步 `setDetail(null)`，派生 `activeDetail` 并在 `doRender`、`linkById`、`PromptDetail` 统一消费。
4. **3 份新增隔离单元测试（FE01-01 / FE01-02 / FE01-03）**：
