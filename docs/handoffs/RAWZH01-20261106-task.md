# RAWZH01 链接原文关联中文阅读

用户明确选择URL导入默认翻译、可取消勾选且告知会调用已配置模型。B评分0/2/2/0=4，因来源完整性与模型外发直接B。按当前agent-router及roles复用已验证实例：Astra规划/独验，原Sol High后端kb03_r1_builder和UI lw03_ui施工；近期RAWUX/RAWURL工程与实际浏览器交付为能力依据，宿主工具支持对应实例，不重新枚举凭据或假装切模型。原HEAD275067c及RAWURL754全绿未提交工作树为基线，保留全部前批工作。

## 用户流程与数据

仅URL来源导入显示默认true的“翻译成中文（会调用已配置模型）”。提交即用户本次翻译授权；取消勾选、文件/粘贴优先分支、主要中文内容均0翻译请求。轻量识别英文及中英混合中实际英文段，不额外模型识别语言，不建立语言平台。先保存原Raw，再开始独立译文任务；成功导入不因翻译失败被伪装成未导入，失败显示原Raw已保存并可单独重试。

原Raw body/SHA/asset/url来源元数据不可AI改写，译文不新建Raw或Wiki。state/raw-translations/<rawId>.json记录rawId/rawSha256、目标zh-CN、提示版本、Provider非敏身份、分段原文范围/译文、状态/进度/实际请求计数/脱敏错误。译文只是派生阅读层，完成默认中文，可切原文；显示AI译文身份。点击原文证据必切原文并精确定位；后续Wiki整理仍读取原文及原offset，不把译文当事实来源。

长文按原文顺序分段（无重叠、无静默截断），已完成段可复用，失败显式继续。每段真实请求前记计数，取消/重启不得自动重新外发；刷新GET只读，双击同Raw当前内容不重复发起。使用既有持久化/队列模式，不新建通用调度平台，不承诺网络exactly-once；中断不确定段可在用户明确继续时重发并计数。完成状态必须全文段落都有结果，部分结果不可冒充完整中文。源SHA/提示/模型身份变化不能盲复用旧部分翻译。

沿现Provider与secret脱敏、Meeting Raw本机外发门禁；起始及实际发送前核源有效性。仅翻译内容，不执行原文指令或添加事实；格式/数值/否定/专名用合成样例验契约，不声称fake证明模型语义质量。翻译未配置/失败不影响原文阅读及既有整理。

## 接口与所有权

后端Sol拥有新services/llm/raw-translations.ts（状态存储可就近单文件）、server/raw-import.ts及server/index.ts必要接线、最小GET/POST /api/raw/:id/translation及取消/显式重试接口、相关类型和新RAWZH01后端/HTTP测试。URL import显式translateToChinese布尔，文件/正文忽略该翻译意图；旧接口未传不自动外发，只有新UI默认true。回包保留raw/extraction并附译文状态，导入失败和翻译失败区分。精确DTO开工前由后端直接发UI并追加卡。

UI Sol拥有RawPage/api/types/必要css，RAWZH01 UI测试/隔离/browser入口与报告；复用RAWURL导入及阅读页，英文/中文切换不改真实资料。语言判定结果/翻译进度/失败可操作，不围绕译文增加人工逐段审批。Astra只改本卡/baseline/review/独立证据和最终status/control，不改产品。

开发仅TEMP synthetic/fake，无真实付费模型、配置读取或修改、正式资料写入；当前用户proxy后台服务不操作/关闭。无提交推送，不扩文件/粘贴自动翻译，保留前批服务接口与预算约定。

## 必验

1. 英文URL勾选默认启动，取消0；中文0；中英混合保中文并翻英文；file/paste+URL默认框状态不能触发翻译，且file仍0fetch。
2. 原Raw SHA/原文/来源不变，译文单独读回且只原文证据；原文不伪作中文、译文不新建Raw。
3. 长文多段进度、失败/取消/重启/显式继续复用、刷新与双击去重、计数及完整状态，坏JSON/缺段/secret/权限/源版本反例。
4. 导入成功但翻译失败保同Raw，重试无再次抓取/新Raw；未配置友好提示；已有中文/取消勾选正常导入无调用。
5. 完整App隔离Chrome勾选/取消、英文默认中文阅读、切原文、失败重试、原文证据定位、中文0调用；截图亲看，不能用仅组件fake代替实际服务链。
6. 定向来源/RAWURL/RAWUX回归、tsc、空envDir build及最终默认测试无新增失败。独立核停写SHA、重跑关键反例，按同版本复用未受影响证据，范围内缺陷交原owner修复。
