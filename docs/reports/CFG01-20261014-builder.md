- app/pages/SettingsPage.tsx：初次读取与重新读取期间禁用 Provider 字段和操作；读取完成后解锁。保留请求序号、卸载标志及迟到响应隔离。

- tests/provider-config.test.ts、tests/provider-config-ui.test.tsx：新增序列化、旧手工反斜线、非 LLM 标记行、无效标记、代理项、真实 Authorization/模型值、编码密钥及 UI 加载回归。

containsKnownSecret 按百分号编码逐层解码到稳定状态，轮数上限为输入长度；即使百分号组里混有非法 UTF-8 字节，也继续识别相邻可解码内容。safeBaseUrl 另行拒绝非法百分号语法和不能解码为 UTF-8 的百分号字节组。
