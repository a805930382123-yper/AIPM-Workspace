### 2. 前端轻量路由模块（`app/router/`，零三方依赖）
- **`app/router/routes.ts`**：
  - `export type AppPage = 'news' | 'home' | 'wiki' | 'raw' | 'prompt' | 'settings' | 'meeting' | 'work' | 'automation';`
  - 声明式 `APP_ROUTES: Record<AppPage, AppRouteDefinition>`（含 `page`、`title`、`ownedQueryKeys: readonly string[]`，其中 `meeting` 拥有 `['meeting', 'mq', 'mt', 'mg', 'mc', 'mp', 'ml', 'mo'] as const`）及 `MEETING_QUERY_KEYS`。
  - 导出纯函数：`isAppPage`、`getPageTitle`、`getForeignQueryKeys`、`stripForeignQueryParams`、`buildUrlWithParams`（使用 `if/else` 避免 `no-unused-expressions`）、`parseLocation`。
  - 导出窗口安全访问辅助：`readLocationSearch`、`readQueryParams`、`updateRouteQuery`（全部通过 `typeof window !== 'undefined'` 访问 `window.location` / `window.history`，禁止裸用 `location`/`history`）。
  - **关键兼容契约**：`parseLocation` 初始未携带合法 `historyState.appPage` 时返回 `'home'`（即使 URL 带 `?meeting=...`）；导航**严禁**向 URL 注入 `?page=`；离开 `meeting` 页仅精准删除 `MEETING_QUERY_KEYS`，完整保留无关查询参数（如 `?keep=yes`）与 `#hash`，其余键删空时 `search` 置为 `''`。
- **`app/router/useAppRoute.ts`**：
  - 导出 `subscribePopState` 与 `useAppRoute()`。
  - `useAppRoute()` 提供 `{ page, pageTitle, navigationGeneration, getNavigationGeneration, navigate }`：`navigationGeneration` 为 React state（供 render/JSX 安全读取），`getNavigationGeneration()` 读内部同步 ref（供事件与异步闭包获取最新代次）；`navigate(destination)` 调用 `stripForeignQueryParams` 并在 `changed` 时 `window.history.replaceState`；统一监听 `window` `popstate`。

### 3. 异步请求代次与作用域查询 Hook（`app/hooks/`）
- **`app/hooks/useLatestAsync.ts`**：
  - 提供 `{ data, loading, error, setError, run, cancel, reset }`。每次 `run(async ({ signal, isCurrent }) => ...)` 递增内部请求序号并取消前一次 `AbortController`；过时请求的结果/异常静默丢弃，不错误修改新请求 `loading`；`AbortError` 视为取消不置错误；组件卸载自动 abort；零 `react-hooks/*` 警告。
- **`app/hooks/useScopedQuery.ts`**：
  - 导出 `serializeScopeKey`、`invalidateScopedQueries(prefix?)`、`clearScopedQueryCache()`、`useScopedQuery<T>(scopeKey, fetcher, options?)`。
  - **关键兼容契约**：`options.cache` **默认 `false`**，避免跨 JSDOM 测试相互污染；仅当显式传 `{ cache: true }` 时启用内存缓存并支持 `invalidateScopedQueries`。
  - `useScopedQuery` 通过派生状态计算返回值，`useEffect` 体内禁止同步调用 `setState`，回调引用在独立 `useEffect` 内同步，零 `react-hooks/*` 警告且天然防止 A→B→A 切回时的旧响应覆盖新选中。
