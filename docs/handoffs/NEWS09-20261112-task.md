## 产品契约

1. 保留研究365日、上海时间、历史提前排除/补位、AIHOT原5条、今日新增＋近30日精选及Raw原期刊保存。正式缓存不重建。新源失败隔离，既有两源照常，不用普通新闻凑数。
2. 国家统计局：只选标题明确“社会消费品零售总额”的官方发布（不把CPI、工业、解读转载自动扩进本批）。目录最多首页＋后续3页，每页解析站内链接/日期并去重，找到足量合格候选即停；最多4详情，最多2成功材料。正文保留社零总体与快消相关粮油食品、饮料、烟酒、日用品等实际披露内容；宏观标题含汽车不能沿用全局汽车关键词一票否决。表格摘录必须连同列头、单位、当月/累计/同比以及限额以上等适用范围；不能把扁平数字无标签拼成结论。无法可靠关联列头就仅摘取完整可核正文，不编造品类数字。入选必须含至少一项快消品类、商品零售或渠道的明确量化正文，不得仅用泛社零标题/宏观概述；无此证据不入选。
3. PwC：消费市场目录动态发现消费者调研报告页，只选与消费者/食品/零售相关且有公开可读PDF的报告；目录1页、最多4详情、最多2 PDF尝试/2成功材料。日期以明确官方发布日为准；只有月时可保留月精度并明确显示，不能虚构1日（若需扩日期类型先提交Sol复核最小接口方案；优先使用存在的完整发布日期）。PDF专属扫描最多40页，NIQ前20页不变；PDF仍≤10MiB、原重定向/超时限制保持。跳过目录/序言，摘取有完整语境的中国消费者调查正文，附物理页码，并须包含实际消费研究量化数据，营销/目录/表单不入选。无可读正文/只有图像不OCR、不调用模型、不以宣传简介充当PDF全文。
4. 材料类型至少区分“官方统计公报”“消费者调查报告”“既有市场研究/报告摘录”；复用research.kind或最小可选元数据，旧缓存兼容。页面明显显示统计“宏观零售统计，非品牌销量”、调查“受访者调查，非实际销量”。统计期/调查期/样本范围仅引用明确原文；无法确定仍提示以原文为准，不把发布日期当数据时期。原摘录内容不得由AI改写。
5. 来源覆盖：新生成快消选择及近期精选补位每sourceId最多2，今天新增与近期精选共同计数；在既有优先排序上跳过已满来源，继续找其他合格来源，总≤5，质量不足保留空额。旧今日缓存若已含某源3–5条不重写/隐藏其已收录条目，标作兼容例外；近期补位不再增加该源。历史日期页原样展示，不回溯改旧选择。
6. 联合报告去重：至少保留规范URL、标题去重，并增加同一明确PDF链接的规范URL判重（本期与成功历史、近期精选均适用）。同一联合报告不同发布页共享PDF时只取既有排序先到的一个，不把不同机构作为两份材料；保留发布来源和原报告可见联合署名，不另造作者。不同PDF但同名同版走规范标题去重；标题及PDF均不同且无明确同报告证据时不做模糊语义归并，记录局限。不得建设通用爬虫或报告实体框架。
