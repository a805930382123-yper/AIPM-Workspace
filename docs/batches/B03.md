# B03：文件导入

依赖 B01；尚未授权施工。读取 PRD §6–8、acceptance A04/A05、R08–R10。

交付：上传 Markdown/TXT/DOCX/PDF；原文件存 assets，提取文本为 Raw；统一元数据与结果；原始文件名仅为元数据。增加用户删除/重新导入 Raw 操作，删除被引用 Raw 时显示影响，不造成静默坏来源。

复用 RawStore.create；明确编码、文件大小、提取边界；文本 PDF 支持提取，扫描/加密/损坏文件若不支持则明确提示。没有解析正文不能显示“入库成功”。不做网页抓取/OCR系统。

验收：四种真实格式样本；中文、空白、损坏、错误扩展名、超限文件；核对原件与提取正文；重复文件不得覆盖旧资料；解析失败后可粘贴补救；删除/重导入需要用户操作。

范围：导入 UI、解析模块、Raw/assets、测试 fixtures、README 支持矩阵。报告真实测试的格式和失败边界。
