## 判定

R1与R2分别评分：数字/口径准确、重要信息覆盖、来源追溯、推断边界各0–5；R2另评噪声清理、重复归并/新增保留各0–5。R1≥17/20且准确/边界≥4；R2≥25/30且准确/覆盖/新增保留≥4。任一重大错数、预计变实际、样本口径混用、原页无法定位、实质方法整段略过或新增结论伪原文，单项直接FAIL，不用总分掩盖。schema通过仅工程条件。逐图核完整输出与最终草稿，列遗漏/错误/重复实例；R2未完成不能PASS。抽样没有真正跨页续表，不能推广本轮为所有真实续表质量已验。

完成后报告实际次数/usage/成本可得性、R1/R2双结论及R3条件是否满足。失败则停并交主线程最小返修建议，不自动追PASS。
