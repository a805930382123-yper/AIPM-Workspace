# RAWOCR01 个人知识库配图分流

授权范围为四轮规划中的第一轮。基线为 `5255cae`。规划与独立审查采用 Astra medium，施工采用 Sol High。按需求明确度、模块耦合、变更风险、已知失败分别评为 1、1、2、0；Raw 完整性与旧记录兼容按 B 模式执行。

## 本轮交付与验收

1. 复用既有网页图片元数据和图序，为同一原图的不同出现位置建立可区分的稳定关联。可在本地 Raw 存储中保存、更新、重读单图派生产物。实测正文逐字节、正文 SHA-256 和正文修订号保持一致，原图仍可定位，旧记录无需改写可读。
2. 新建供新导入与历史迁移共用的本地纯函数。按规格第 3 节集中阈值，返回三种初始状态及计算指标和命中原因。仅达标纯文字生成清洗文本，保留原始 OCR 供内部核对。
3. 固定图标 80×80、横条 800×60、低字数装饰图、缺少尺寸、无坐标或置信度、正常技术术语、中文列表及软换行、流程图、对比表、含 KRCHANEAPRM 的碎片化榜单样本。榜单同时覆盖真实规则可检测的异常模式，核查 high_gibberish 原因；不得对样本词设特例。覆盖阈值边界、异常符号及有坐标和纯文本两条计算路径。
4. 验证普通接口不会暴露新存储的调试用 OCR。原有导入和阅读路径的切换属于第三轮；VLM、草稿集成和历史迁移分别属于第二轮和第四轮。

## 交接

Sol 负责 Raw 模块、必要的接口投影、定向测试及施工报告；主 Agent 管理任务、状态及 Git 同步。Sol 自查通过、交接停写后，独立 Astra 审查差异、复算样例、重跑存储与回归检查，分别裁决本轮缺陷与批次结果。隔离测试按 docs/testing.md 执行；真实 Provider 预算为零。验收汇报后停止。
