# NEWS17 每日资讯来源标识

以实际注册的九个 AI 来源、六个快消来源为准。AI 抽屉、快消卡片的来源标签、两栏来源诊断分别使用 26、16、20 像素图标。机构使用白底圆角方形，个人使用圆形头像，Karpathy 的四个渠道共享头像并标出平台。

脚本获取并验证图片后在本地托管，获取失败时生成品牌缩写 SVG。已知来源按 ID 或规范化名称匹配；未知来源按官方地址尝试远程图标，最终可显示确定性配色的文字标识。验收覆盖文件有效性、幂等、生产构建、三个实际展示位置和加载失败。项目未配置独立 lint 命令。

需求明确、涉及资源和少量视图接口、变更可回退、无相关历史失败，评分 0/1/0/0。按用户指定模型分工，GPT-6.2 Sol High 施工，GPT-6.2 Astra Medium 独立验收。
