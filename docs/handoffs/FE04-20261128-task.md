## 冻结实现方案与不变量

1. 原入口保留三项导出与原 props 类型、默认值、回调参数及调用次序；允许从原路径 re-export 弹窗。App 和既有测试无需改导入。
2. `RawPage` 保留组合壳；页面状态集中到 `raw/useRawSelection.ts` 或同义名称 hook，包括筛选、选中项、导入/删除/综合开关、提取世代和回调。不改变原有 hook/effect 顺序与清理语义，不增加通用状态框架。
3. `raw/RawDetail.tsx` 保留详情组合和 keyed remount 边界；将翻译/主题/任务恢复等原状态逻辑连续迁入 `raw/useRawDetail.ts`，必要将 AI 状态/操作区域抽成展示组件，避免另造一个超限大文件。原 `key={selected.id}`、`initialOriginal`、引用哈希/位置检查及 PDF/meeting-only 条件不变。
4. 独立 `SynthesisDialog.tsx`、`RawBodyEditor.tsx`（可含历史，合计约 212 行）、`ImportDialog.tsx`、`DeleteDialog.tsx`。导入结果/部分提交面板可单独 `ImportResultPanels.tsx`。仅共享实际复用的 PDF 判定等轻量类型/函数；单用标签解析、错误转换随所属模块，不为拆分制造泛用抽象。
5. 所有本批产品文件必须同时 **< 40,960 B 且 < 800 行**，入口明显缩小，无运行时循环、子模块不反向导入 RawPage 门面。类型导入用 `import type`。不通过压缩代码或改格式规避尺寸。
6. 行为等价：API 路径/method/payload、错误码处理、正文精确字节、onCommitted 先于退出/生成、部分提交不伪报成功、同一 Raw 生成重试、翻译只为派生显示、正文人工修订版本保护、恢复不重新生成、标准/深度继续模式、综合来源去重、防重入、焦点/DOM/CSS/文案保持。AI 输出不写 Raw；正式 Wiki/Prompt 不自动写入。
7. 不顺手修理已存在的非本批问题。提取后 lint 不得新增错误/告警，至少维持基线；不要求为清零存量告警改行为。
