## 冻结范围

- 保留标题与周期回顾、顶部四个真实入口：导入资料、审核草稿、生成 Prompt、新建会议。沿 DESIGN.md 已批紫白 tokens、系统字体与轻边线。
- 顶部入口之后直接进入桌面双栏：左约 2/3 为“需要你处理”主任务流，右约 1/3 为“到期跟进”和独立“每日资讯”卡片。主任务先于次级信息；左右顶边对齐。不要引入多重内部滚动或为卡片强塞等高空白。
- 最近知识/更新、统计与最近导入降到主工作区之后；本批保留其功能，不新增汇总模型、排序规则或接口。行动列表、稍后处理、来源错误、加载/空态、刷新、过滤和跳转继续可用。
- 去掉底部重复的“仅保存 Raw”“生成 Prompt”等主动作；非重复的从 Raw 生成草稿、手动创建 Wiki、新建 Prompt、检查知识库保留为清楚可达的“更多工具”区域（可折叠）。不能仅为减少按钮而删掉能力。
- 仅用 HomePage 容器与首页 scoped CSS 将现有 NewsHome 置入右侧独立卡片，标题、真实准备状态、错误与“阅读资讯”入口可读。不改变其挂载数量、fetch 或准备逻辑。
- 可修两个明确 UI 问题：从审核过滤再点 Audit 统计入口时清掉审核过滤，使 Audit 可见；首次 actions 读取失败时结束“正在读取事项”文案，显示失败与刷新。不得新增自动重试。
- 手机单列顺序：四入口→主任务→到期跟进→每日资讯→次级最近内容/统计/工具；长标题换行，按钮和焦点完整可见，无横向溢出。断点按可用宽度选择，不重做全站导航。
