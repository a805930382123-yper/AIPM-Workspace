## 第一步 真实使用后作继续或停止决定

1. 用一项真实产品分析记录 WORK03 首轮、补料及续轮；记录 WORK04 复核是否发现需要人处理的问题，以及追加资料后用户是否用建议回到分析。记录实际采用、错过或忽略的建议与原因。现有客户推进建议可记录试用结果，试点不扩展到客户通知。
2. 用去敏记录说明至少一次真实补料的来源、谁搬运、漏掉的环节、收到资料到开始分析的间隔，以及同一来源是否会重复出现。确认应用内的提醒和手动关联仍有哪些缺口。没有可重复的来源、明确价值或合法处理范围时，停止在评估阶段，保留现有人工流程。
3. 仅对一个已观察到的补料场景定范围。由用户确认资料授权、运行方式和接收位置，主线程冻结下表与可观察的通过标准后，再决定是否批准施工。WORK05 此时只描述评估和试点边界，前两阶段的试用结论仍决定是否实施外部触发或后台执行。

## 第二步 推荐的最小试点（待冻结）

- 优先让唯一批准来源向本机固定投递目录交付一份文本型事件文件，由本机产品服务在获批运行时段读取。使用一个固定的来源和事项映射，传入文件不能指定路径或任意事项。本机服务继续监听回环地址。只在服务运行时处理；停服期间如来源仍能投递并保留文件，复机可扫描这些已留存文件。
- 建议最小事件字段为 `{eventId, title, body}`，来源命名空间和目标事项 ID 由接收端配置。冻结后才定文件格式、上限、路径及扫描频率。`body` 作为原始资料原样保存；缺字段、未批准或受限内容、目标找不到或已关闭时停止并显示可处理原因。只接受获批来源具备归档授权的文本，不替 Meeting 档案或其他原件绕过现有权限。
- 复用 Raw 导入和 `WorkItemStore` 的关联写入。接收标识为 `(source, eventId)`，用它定位已有 Raw 并直接对照保存的原文。同一标识、同一内容只关联一次，内容变更保留冲突。写 Raw 后、关联前中断时，须能按该标识找回原 Raw 并补关联。关联在现有事项串行写入与 `revision` 下追加，避免覆盖用户编辑。接收记录留事件标识、Raw ID、事项 ID 和状态，正文只归 Raw。记录复用可备份的现有目录范围，具体格式及落点开工前确定。
- 成功后在同一事项的「资料」看到新增 Raw；符合 WORK04 既有条件时展示继续分析建议。关闭或停用试点保留已入库资料与历史；待处理文件按冻结的保留规则处理。补料只同步与关联，分析仍由人选择资料后显式发起。首页沿用现有到期规则。

## 独立验收（仅在试点获批后）

| ID | 关键操作和可观察结果 |
|---|---|
| W05-01 | 用实际接收入口投递获批格式样例，原文只生成一条 Raw，关联唯一已存在事项并在实际 Chrome 看到继续入口。验证没有模型调用、对外通知或 Wiki/Prompt 写入。 |
| W05-02 | 同一事件再次投递、重启或恢复后仍只生成一条 Raw 和一处关联。注入写 Raw 后关联前的中断，恢复时用原 Raw 完成；同 ID 内容变更、未获批来源、超限、关闭或未知事项可见拒收或冲突，不把失败当成功。用户同时保存其他字段时不被覆盖。 |
| W05-03 | 按冻结的运行时段和停用操作验证接收进程。停服时不发生处理；若投递方能留存，复机只处理仍保留且合规的事件。试点备份恢复后原文、关联和接收状态一致。 |
| W05-04 | 用户另行批准后对真实来源验证一条低敏实际事件，记录到达、入库、定位原事项及可用性；样例和证据去敏。未获授权或来源不可用时，真实接入写 `NOT_RUN` 或 `BLOCKED`，结论限于隔离工程验证。 |

独立验收报告附实际命令、结果、受验提交标识，分别裁决本轮缺陷、试点整批与真实使用价值。运行和外部接入证据不得由合成文件替代；先完成可隔离验证的行为。

## 预算、所有权与退出条件

- WORK05 计划真实模型调用 0。第一步复用 WORK03/04 经批准的实际使用证据，历史额度保持原账本，评估或补料均不自动触发模型。正式环境接入与资料范围按冻结后的用户授权执行。
- 条件满足后，施工在既有 `services/raw/store.ts` 导入边界、`services/work-items/` 关联与接收记录、`server/index.ts` 必要接线及工作事项界面范围内分配；若采用本机文件投递，验收覆盖选定的接收入口。规划/独验持有冻结接口与证据，施工交接后停写，主线程统一状态、提交和同步。
- 同一来源稳定送达、没有重复入库或漏关联，应用内提醒能解决已观察到的补料缺口时，试点可继续供该事项使用。价值未观察到、来源无法提供稳定身份、权限无法满足，或出现未处理的资料完整性问题时，暂停接收并回人工关联。扩展来源、事项或运行范围另议。
- 试点排除通用 webhook 平台、通用队列、长期任务引擎、多来源自动路由、飞书全套接入、外网监听、自动分析和外部消息。范围以一个现有事项的外部补料为限。
